# ComfyUI 工作流总调度规范

本技能定义「ComfyUI工作」预设下的标准作业流，以“严谨工程、闭环审查”为核心原则。

## 四阶段推进原则

任何生图或工作流任务必须遵循以下四个阶段：

### 阶段一：提示词指导查核（先查现有指导）
1. 用户提出生图需求并指定（或涉及）特定生成模型时，**先检查本地是否有该模型的提示词指南**：
   - 检查预设技能库（如 `moss-image-guide`、`Workflows/` 目录说明文档）。
   - 检查工作区历史记录或相关配置文档。
2. 明确该模型的提示词特性：
   - 支持语言（例如 MOSS-Image 原生支持中文自然语言；SD1.5/SDXL/Flux 英文提示词更优等）。
   - 负向词需求（MOSS-Image 可留空；SD 系列需常规负向词质量词）。
   - 特殊控制语法（如排版标注框、LoRA 触发词、质量标签权重）。
   - 推荐参数约束（默认宽高、采样器、步数、CFG 等）。

### 阶段二：缺口调研与确认（无指导则先研后问）
1. 若本地知识库没有该模型的现成指导：
   - **严禁凭空臆造提示词规则**！
   - 立即使用 `web_search` 和 `web_fetch` 调研该模型官方发布报告、开源仓库 README、社区最佳实践与推荐工作流参数。
   - 整理出关键要点：提示词语法规范、负向词要求、推荐分辨率、推荐采样器与步数、常见翻车点。
2. **向用户确认**：
   - 将调研到的要点、拟采用的提示词草案以及推荐工作流参数汇总，向用户确认或征询倾向。
   - 双方确认后，将要点沉淀，再进入下一阶段。

### 阶段三：工作流编排与执行
1. 根据用户需求与模型要求准备工作流与执行工具（双轨协同）：
   - **快捷生图 / 标准文生图（优先首选）**：
     - 使用全局工具 `mcp__image__generate_comfyui`：
       - 原生智能路由：中文或海报文字排版自动路由到 MOSS-Image，英文通用走 Qwen Image 2.1，无上述模型回落 SD1.5；
       - **图生图/图像编辑：传 `input_images`**（1–16 张绝对路径）。工具自动上传参考图、接好 `TextEncodeQwenImage21` 的参考图口并切换 latent；仅 Qwen Image 2.1 管线支持，路由落到 MOSS/SD 时工具直接报错而非静默忽略；
       - 支持模板直接传参：传入 `workflow_path: "Workflows/moss-image/moss-image-sft-t2i.json"`，工具将自动注入提示词、种子和尺寸，自动完成落盘与会话图片返回。
   - **深度工作流编排与模板管理**：
     - 使用本预设特有的 `comfy-mcp` 工具集：
       - `mcp__comfyui__search_templates` / `mcp__comfyui__get_template`：查找与下载模板；
       - `mcp__comfyui__validate_workflow` / `mcp__comfyui__workflow_deps`：检查工作流完整性与依赖；
       - `mcp__comfyui__run_workflow`：执行复杂定制工作流并支持后台轮询；
       - `mcp__comfyui__job` / `mcp__comfyui__fetch_outputs`：管理排队与拉取输出。
2. 参数确认无误后提交生图，监控任务状态至完成，获取输出图片路径。

### 阶段四：生成结果严格审查（核心必做）
1. 获得生成图像后，**绝不可盲目交付完成**！
2. 必须使用 `read_image` 仔细查看生成的图片文件。
3. 严格依据 `image-generation-review` 技能展开多维度审查：
   - 构图合理性、空间分布与视觉焦点。
   - 文字渲染正确性（中英文是否缺笔少画、错别字、镜像乱码）。
   - 人物/动物肢体、面部五官完整度与结构正常性。
   - 材质质感、光影一致性、artifact（伪影/噪点/撕裂）。
4. 审查不合格时，分析原因并主动提供优化策略（调整 seed、微调 CFG/步数、修正提示词或切到专用控制工作流），向用户说明；合格后使用 `present` 进行交付。
