# 图像生成结果严格审查规范

在「ComfyUI工作」预设下，**生成出图绝不等于任务结束，严格审查是产出合格成果的必要屏障**。

## 审查流程与操作 checklist

- [ ] 1. **获取并打开原图**：
  - 定位 ComfyUI 生成并保存的图片路径。
  - 必须使用 `read_image` 工具读取并查看图像实际内容（禁止仅凭文件名或执行状态判定生成成功）。
- [ ] 2. **全维度质检核查**：
  - **构图与主体**：主体是否完整、空间分布是否失衡、有无被意外裁剪出画。
  - **解剖结构与细节**：人物或生物的眼睛、五官对称性、手部指头数量、四肢关节是否自然畸形。
  - **文字渲染质检（极为关键）**：若提示词包含文字（标语、招牌、海报文字），逐字检查文字笔画、有无错别字、倒装或乱码伪影。
  - **画面伪影与材质**：检查背景有无明显的噪点块、接缝裂纹、重复伪影、过度锐化或异常光晕。
  - **提示词对齐度**：用户明确要求的元素（颜色、特定物体、时代风格、光影基调）是否全部在画中体现。
- [ ] 3. **评估与反馈**：
  - 向用户汇报审查结论，说明画面亮点与存在的细节瑕疵。
- [ ] 4. **缺陷处置与迭代策略**：
  - 若存在明显瑕疵（如文字乱码、肢体变形）：
    - **随机性偶发瑕疵**：保持提示词与参数不变，更换 `seed` 重新采样。
    - **文字笔画瑕疵**：检查是否使用了适合的文本引导节点（如 MOSS Image 的 Layout 模式），或在提示词中强化文字引号与独立分段。
    - **画面过饱和/烧色/结构坍塌**：适当调低 CFG（如从 3.5 降至 2.5 或 2.0）。
    - **细节欠佳/模糊**：适当增加采样步数（如 20 增至 25-30 步）或检查 scheduler。
- [ ] 5. **成果交付**：
  - 审查确认合格后，使用 `present` 工具将图片文件卡片呈现给用户。
