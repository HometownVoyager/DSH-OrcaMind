# 角色声音（character-voice）

## 何时使用
- 角色定型时建立声音档案。
- 写作对白与内心独白时对照查用。
- 用户抱怨"所有人说话一个样""对白不像他"时。

## 声音档案（00-设定/character-voices.md）
每个主要角色一节：
```markdown
## <角色名>
- 词汇域：<常用词/术语/避用词>
- 句式：<长句/短句/反问多/爱打断别人>
- 口头禅与语癖：<具体例子>
- 情绪表达：<愤怒时/悲伤时/说谎时各怎么说话>
- 话题回避：<从不提什么>
- 身份痕迹：<职业/阶层/时代如何体现在语言里>
- 台词范例：<2–3 句带性格的示范对白>
```

## 内心独白：角色的第二声部
- 内心独白与对白是两个声部：对白是角色想让人听到的，独白是角色自己的声音——可以更坦率，也可以更自我欺骗；写前先确定该角色的独白口径并记入声音档案。
- 独白口径要稳定：一个人不会一章碎碎念、下一章变成冷眼旁观；除非角色经历了有依据的转变。
- 内心独白受视点配置系统约束（多心声禁令：一个段落或场景内内心特权只有一份），违规判定见 pov-craft。
- 独白与叙述的融合方式（自由间接引语等）见 pov-craft。

## 对白写作原则
1. 潜台词优先：人很少直说真实意图；对话的"真实内容"在没说出的部分。
2. 问答不对称：A 问 A 的，B 答 B 的——回避本身就是信息。
3. 少直说：情绪标签（「我很生气」）换成行为与措辞的变化。
4. 符合关系：同一角色对上司、爱人、陌生人说话完全不同，但"声音内核"一致。
5. 符合身份与时代：用词准确，不做现代语穿越（除非题材允许）。
6. 每个人至少一个语言识别特征：读者遮住名字也能认出是谁在说话。

## 检查
- 写完一场戏/一章，把对白与独白逐行对照声音档案过一遍。
- 发现角色说话"漂移"时，优先修正对白而不是改档案（除非角色经历了有意的转变——那种转变要在剧情里有依据）。
- 对白同样遵守反翻译腔与金句克制（见 writing-craft）。

## 跨媒体改编附录
若作品未来改编为互动叙事/游戏形式，选项文本也必须符合对应角色的声音（不写角色不会说的选项）；详细改编规范以「剧本创作」预设为准。
