# 游戏电竞类型惯例（genre-esports）

## 何时使用
- 开题判定作品类型为游戏电竞（职业选手成长、战队经营、赛事竞技，含网游竞技向作品），或混合类型中声明含电竞元素时，全程加载本 skill。
- 游戏设定、赛事设计与成长线各阶段对照本 skill 检查；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 游戏载体决策：开题先定「现实游戏还是虚拟游戏」——现实游戏按 research-materials 考据其机制与赛事生态；虚拟游戏需自建设定（玩法、职业、地图、版本）并落盘为 00-设定/ 的专项文件，两者不得混用。
- 赛事结构：联赛/杯赛/预选/升降级构成赛季节奏，写明赛制（BO3/BO5、积分制、赛程）与晋级逻辑；比赛结果必须由双方的真实实力、战术与临场状态推演得出。
- 游戏理解：版本生态（强势英雄/战术体系/克制关系）、地图资源、团战逻辑——比赛的胜负手藏在细节里（视野、时机、资源交换），写比赛就是写这些细节。
- 团队与选手：五个位置（或对应结构）的职能分工、指挥与配合、轮换与替补；选手的状态起伏、伤病、年龄、合同与舆论构成场外线。
- 成长线：从路人王到职业的路径（青训、次级联赛、首发、成名）有真实台阶；成长靠训练、复盘与心性磨炼，不靠主角光环单骑救主。

## 经典结构变体
- 职业选手成长：主角从青训/路人起步登顶，重点是竞技能力的真实成长与代价（伤病、舆论、年龄）。
- 战队经营：经理/教练视角，组队、引援、预算、版本调整与更衣室管理，群像感强。
- 退役转型：从选手到教练/解说/主播的转型，竞技的遗憾与第二人生。
- 网游竞技：以游戏世界内冒险为主、竞技为辅，注意与纯竞技文的节奏差异（冒险线占大头时按 genre-fantasy / genre-scifi 等对应类型叠加）。

## 读者期待
- 赛事专业性：赛制、战术、版本理解经得起内行读者推敲；比赛的胜负逻辑让人服气。
- 比赛描写的紧张感：BP（选禁）博弈、关键团战、翻盘与失误都写得专业且扣人心弦——按场景经济学写清关键瞬间，不流水账。
- 成长线可信：实力提升有过程（训练、复盘、战术学习），输得有原因、赢得有依据。
- 团队的真实感：队友不是工具人，配合与磨合、信任与矛盾都是戏。

## 常见坑
- 游戏机制失真：比赛写得像「主角一穿五」的爽文，无视团队配合与版本逻辑——每场胜负按战术与状态推演。
- 主角光环救场：关键局全靠主角绝境爆发、对手降智——写实力与心理的真实博弈，对手也是聪明人。
- 版本生态混乱：英雄强度、战术体系前后矛盾——版本设定成表管理，改动要说明理由。
- 现实影射红线：影射真实选手/战队的丑闻、假赛等负面情节有法律与道德风险——涉及现实赛事时避免对号入座式负面设定，必要时声明纯属虚构（写入 规范-创作.md 红线节）。
- 场外线喧宾夺主：合同、八卦、恋爱情节淹没比赛主线——场外线服务于竞技成长，比例由用户拍板。

## 文风与称谓惯例
- 赛事转播式描写：关键局用清晰的战报笔法（时间点、资源交换、关键操作），让读者像看直播一样看得懂、跟得上；解说不必照搬，但节奏参考转播。
- 术语准确且可懂：游戏术语（BP、经济、资源点）首次出现即在语境中说明，面向非玩家读者也读得懂；术语前后一致并记入 glossary。
- 对白贴合电竞圈：选手、教练、解说的说话方式各有味道（赛场内外、镜头前后），但保持完整句子的句式纪律。
- 热血克制：竞技的热血靠比赛细节与人物付出自然涌出，不靠口号与感叹号堆砌（见 writing-craft 金句克制与汉语语感）。

## 与其他 skill 的配合
- 设定阶段：游戏机制、版本生态、赛制写入 00-设定/ 专设文件（虚拟游戏尤其要完整设定），战队与选手档案写入 factions.md 与 characters/。
- 现实游戏考据：英雄机制、赛事规则、选手生态按 research-materials 规范查证并注明来源，区分现实事实与创作设定。
- 大纲与正文阶段：赛季节奏、关键比赛与成长节点排入 novel-outlining；正文对照 writing-craft 执行场景经济学与节奏纪律，本 skill 负责赛事专业性与胜负逻辑核查。
