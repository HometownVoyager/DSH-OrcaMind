# 奇幻类型惯例（genre-fantasy）

## 何时使用
- 开题判定作品类型为奇幻，或混合类型中声明含奇幻元素时，全程加载本 skill。
- 设定集、大纲与正文各阶段对照本 skill 检查力量体系边界、种族文化与基调统一；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 力量体系与边界：魔法/力量必须写明来源（神恩/血脉/秘术/自然元素等）、施法条件（媒介、吟唱、材料、环境）、代价（寿命、理智、献祭、反噬）与边界（什么做不到）；边界比上限更重要——读者信服一个「有限但有巧思」的体系，反感一个「无所不能」的体系。
- 种族：人类、精灵、矮人、龙、魔物等种族各有生理特征、寿命尺度、文化传统与相互关系；种族差异要渗透进角色的时间观、价值观与言行，而不是只换皮。
- 地理：大陆、城邦、秘境与政治版图要和情节呼应——地图上的每个地名最终都要与故事发生关系，反对设定宏大而情节缩在一个城。
- 时代基调：开题即定史诗或低魔基调（见「经典结构变体」），基调决定文风、冲突尺度与魔法密度，中途不得漂移。

## 经典结构变体
- 史诗奇幻：多线叙事、王国兴衰、群像视角，尺度大、节奏缓、格局感强；要求时间线与多线交汇点的严密管理（配合 continuity）。
- 低魔奇幻：魔法稀少、代价沉重、世界更写实，冲突更多来自人与制度的博弈而非法术对轰。
- 剑与魔法冒险：小队游历、任务式推进，节奏明快，适合网文连载；注意别退化成换地图打怪。
- 英雄之旅成长流：凡人到英雄的经典弧线，结构清晰但需要新鲜的类型元素支撑，避免套路化。
- 黑暗奇幻：残酷世界观、道德灰色，基调统一要求最高——残酷要有叙事意义，不为虐而虐。

## 读者期待
- 魔法规则自洽可推演：读者能顺着规则预判术法的合理运用，主角的胜利必须来自规则的巧妙运用而非新规则空降。
- 世界真实感：衣食住行、经济、信仰、语言习惯构成可触摸的世界，而不只是城堡与森林的布景。
- 基调统一：史诗感或幽暗感从头贯穿，情绪与文风不跳档。
- 种族文化有深度：每个种族有自己的逻辑与尊严，不刻板、不工具化。

## 常见坑
- 魔法万能化：遇到问题丢一个法术、主角掌握所有体系——魔法必须有限、有代价、有专精方向。
- 设定堆砌无情节：设定集越来越厚、故事不动——设定为情节服务，先有故事需求再补设定。
- 种族刻板印象：精灵必高洁、矮人必酗酒、兽人必野蛮——给种族内部差异与个体反例。
- 造词混乱：人名/地名/神名无规则、前后不一——建立统一的命名规则（音韵、构词习惯）并记入 glossary。
- 魔法与物理的冲突写一半：引入魔法后现实规律说崩就崩——确定魔法介入现实的边界并贯彻。

## 文风与称谓惯例
- 史诗笔调克制庄重，低魔笔调写实冷峻；无论哪种，禁止翻译腔与欧化长句堆叠（见 writing-craft 汉语语感）。
- 人名、地名、族裔称谓、神名、法术名前后一致，读音顺口、构词符合所属文化（如精灵名多流音、矮人名多重音）。
- 对白随种族文化变化：长寿种族说话更从容、看淡生死，短寿种族更急迫——差异通过言行呈现，不靠旁白贴标签。
- 神与信仰的称谓保持敬畏距离：神名、祷词、咒语各成体系，不与日常口语混淆。

## 与其他 skill 的配合
- 设定阶段与 story-bible 配合：力量体系边界与代价写入 world.md，种族文化写入 characters/ 与 glossary，势力与地理写入 factions.md、geography.md。
- 大纲与正文阶段：多线叙事（史诗奇幻）的时间线与交汇点按 continuity 登记追踪；正文对照 writing-craft 执行场景经济学与唤醒度纪律，本 skill 负责力量体系边界与基调统一核查。
