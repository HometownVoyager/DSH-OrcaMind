# 历史架空类型惯例（genre-historical）

## 何时使用
- 开题判定作品类型为历史架空（正史演绎、历史穿越、历史群像、历史悬疑），或混合类型中声明以历史时代为背景时，全程加载本 skill。
- 史实考据、时代还原与虚实边界各阶段对照本 skill 检查；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 史实考据纪律：涉及真实朝代、人物、事件、制度时，按 research-materials 规范考据——官制、军制、赋税、历法、地理、器物、语言都要查有出处；考据结果落盘为 00-设定/ 的时代资料档案，注明来源。
- 时代细节与观念还原：写「那个时代的人」而非「穿着古装的现代人」——等级观念、家族观念、时间观念、卫生与医疗、信息传播速度都按时代来；角色的欲望与恐惧要放在时代条件下成立。
- 虚实边界：真实历史与虚构情节必须分清并声明——动了哪些真实人物与事件（改名/改结局/改动机）、架空改了什么，开题与用户确认，并记入 规范-创作.md 或作品说明（如序言/后记/注释）。
- 历史逻辑：情节要顺着历史条件推演（生产力、交通、制度、战争逻辑），人物的选择受时代约束——架空改动的连锁后果要推演到位（改了一处，其后全部联动）。

## 经典结构变体
- 正史演绎：依托真实历史脉络创作，历史大走向不变，人物内心与细节虚构——考据最重，改编处必须注明。
- 架空历史（穿越改变历史）：现代人/技术/观念进入古代，或历史关键点被改变——核心是「蝴蝶效应」的推演纪律：改动一处，制度、军事、经济、人心的连锁变化都要推演，不能只改结论不改过程。
- 历史群像：多人物多阶层视角写一个时代断面——各阶层的生活质感与观念差异要分明。
- 历史悬疑：用悬疑结构写历史谜案——参考 genre-mystery 的线索纪律，但证据规则要符合时代（没有现代刑侦手段）。

## 读者期待
- 考据扎实：制度、器物、事件经得起推敲，读者查证不塌房；考据错误会摧毁信任。
- 时代质感：衣食住行、语言观念、权力结构有历史的分量，读着像进了那个时代。
- 虚实分明：读者清楚知道哪里是史实、哪里是创作；混淆或隐瞒改编是失信。
- 历史逻辑自洽：架空改动的连锁推演完整，不出现「改了科举却还有八股取士的官场生态」这类断链。

## 常见坑
- 时代错误：官制、纪年、称谓、物价、技术穿越——时代资料档案落盘后每轮对照，拿不准即查。
- 以今代古：现代价值观、现代语言、现代效率硬套古人——观念与语言随时代切换，主角可以现代（穿越者），世界不行。
- 史实与虚构混淆：改历史不声明，误导读者——改编清单开题定稿并落盘声明。
- 考据堆砌：史料堆成说明文打断叙事——考据藏在细节里（服饰、称呼、器物、惯例），不写论文。
- 架空推演断链：只改起点不改连锁——改动处画出影响链，逐层推演并随 continuity 核查。

## 文风与称谓惯例
- 语体贴合时代：叙述可用文白相间的笔调，对白按时代与身份——官员有官场语、市井有市井腔；穿越者主角的现代思维与时代语体的错位是天然看点，分寸按设定执行。
- 称谓体系准确：官职称谓（品级、差遣、尊称）、亲属称谓、纪年方式（年号/干支）前后一致且合于时代；错称即穿帮。
- 量词与物价按时代：银钱、度量衡、物价尺度符合时代，不写「随手一锭银子」的失真桥段。
- 引文与典章注明：引用史料、诗词、典章时按 规范-创作.md 的引用格式注明出处，不张冠李戴。

## 与其他 skill 的配合
- 设定阶段：时代资料档案（制度/纪年/称谓/物价）写入 00-设定/ 专设文件并注明来源；timeline.md 管理真实时间线与虚构时间线的对应关系。
- 考据：所有史实性内容按 research-materials 规范联网查证、注明来源，区分史实、考据推断与创作设定三级。
- 大纲与正文阶段：历史大事件与虚构情节的咬合点排入 novel-outlining；正文对照 writing-craft 执行场景经济学与汉语语感纪律，本 skill 负责时代准确性与虚实边界核查。
