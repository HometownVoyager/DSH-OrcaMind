# 恐怖灵异类型惯例（genre-horror）

## 何时使用
- 开题判定作品类型为恐怖灵异（含克苏鲁、民俗怪谈、心理恐怖、生存恐怖），或混合类型中声明含恐怖元素时，全程加载本 skill。
- 恐惧来源设定、氛围营造与节奏控制各阶段对照本 skill 检查；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 恐惧来源：未知之物、污染与异化、仪式与禁忌、民俗规则、人心深处的恶——开题先定「怕的是什么」，并定恐惧的运作规则（谁会被盯上、如何触发、如何躲避/对抗）。
- 规则型设定：灵异与怪谈要像规则游戏一样自洽——触发条件、代价、破局方法要能推演；「无所不能的鬼」和「突然被感化的鬼」同样败兴。
- 渐进与异化：恐怖来自日常的缓慢异化——熟悉之物变得不对劲（钟摆的方向、邻居的笑容、镜中的自己），比怪物突脸更持久。
- 不可名状与留白：真正可怕的东西说不清、看不全——用缺失、局部与后果暗示全貌；写足「不可名状」的压迫感，而不是给它一份设定书。
- 安全阀节奏：恐惧需要呼吸——高压段落之间安排缓冲与虚假安全，让读者喘口气再跌入下一层，全程高压会麻木。

## 经典结构变体
- 克苏鲁式：不可名状、理智侵蚀、人类渺小——核心是「知晓的代价」，知晓越多越危险，对抗往往是徒劳或两害相权。
- 民俗怪谈：地方禁忌、仪式、因果报应——规则来自民俗传统，氛围来自乡土日常的异化，考据真实民俗时按 research-materials 注明来源与改编处。
- 心理恐怖：威胁可能只存在于角色心里（或不确定），叙述的可靠性本身成为恐怖手段——写清「不确定」的边界，不拿精神病当万能借口。
- 生存恐怖：封闭空间、资源有限、逃生解谜——威胁实体化，节奏靠资源与空间的压迫推进。

## 读者期待
- 恐怖渐进可信：恐惧层层加码，每一步都有铺垫与逻辑，不靠「突然吓一跳」充数。
- 规则自洽：怪谈规则（触发、代价、破局）前后一致，读者能顺着规则推理危险。
- 留白不空洞：留白是「有东西但看不全」，不是「什么都没写」——暗示要足够，让读者的想象补全恐惧。
- 角色反应真实：恐惧的反应链（否认→确认→逃避→对抗/崩溃）符合人性，降智作死与全程冷静同样失真。

## 常见坑
- 血腥堆砌：靠血肉与惨状制造廉价刺激——恐惧在氛围与规则，不在器官展览。
- 鬼怪能力无规则：力量忽强忽弱、破局全靠巧合——规则开题定稿并贯彻。
- 恐惧疲劳：全程高压无缓冲，读者麻木——按安全阀节奏排布松紧。
- 结尾解释过度或不足：谜底说太满（恐怖消散）或完全没底（像烂尾）——在「可理解的规则」与「不可名状的核心」之间找落点，开题即定揭示到什么程度。
- 精神疾病当万能梗：把精神分裂/幻觉当反转万能钥匙——心理恐怖要写「不确定」，而非甩锅给诊断。

## 文风与称谓惯例
- 克制的日常笔调最吓人：用平静、精确的笔调写异常——叙述越冷静，异常越刺耳；避免满篇形容词与感叹号。
- 感官细节优先：声音（半夜的水滴、异常的安静）、气味、触觉、温度变化——恐惧从感官细节渗入，不靠「好可怕」直给。
- 称谓按规则体系：民俗怪谈用乡土称谓（婆/爷/童），克苏鲁体系用其专名惯例，仪式与禁忌用语前后一致并记入 glossary。
- 恐怖段落的句式随压迫感收紧：句长缩短、节奏加快，但保持完整句子与逻辑流动（句式红线见 persona 内容质量规则）。

## 与其他 skill 的配合
- 设定阶段：恐惧来源、规则、禁忌写入 world.md 与 glossary.md；怪谈规则与触发条件随 continuity 追踪一致性。
- 大纲与正文阶段：恐惧渐进曲线与安全阀节奏排入 novel-outlining 的节奏结构；正文对照 writing-craft 执行氛围与唤醒度纪律（平静之下的暗流），本 skill 负责规则自洽与留白分寸核查。
- 涉及真实民俗、仪式、心理病理时，按 research-materials 规范考据并注明来源与改编处。
