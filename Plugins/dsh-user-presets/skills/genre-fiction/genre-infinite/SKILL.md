# 无限流·规则怪谈类型惯例（genre-infinite）

## 何时使用
- 开题判定作品类型为无限流/规则怪谈（主神空间、副本轮回、规则求生、循环解谜），或混合类型中声明含此类元素时，全程加载本 skill。
- 副本规则设计、成长体系与跨副本一致性各阶段对照本 skill 检查；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 副本循环结构：主角进入一个个独立副本（场景/世界/怪谈），通关获得奖励，失败付出代价——开题即定「为何进入、谁在主持、通关标准、失败代价」四大基础设定。
- 规则设计：每个副本的核心是规则——明规则（写在纸面上的）、暗规则（需要试错推出来的）、规则漏洞（破局的钥匙）；规则必须精确、可推演，破局必须由规则本身推导出来。
- 道具与成长体系：通关奖励（道具/积分/强化）构成成长线，道具用途、限制、冷却与兑换体系要成表管理；成长与副本难度同步爬升，避免后期道具通货膨胀。
- 跨副本一致性：各副本世界独立，但总规则（兑换、惩罚、能力体系）恒定；主角带出的能力在后续副本中的表现前后一致。
- 群像与博弈：队友、对手与 NPC 构成博弈场——信任、背叛、合作的分寸是剧情张力来源；NPC 的动机要自洽，不是布景。

## 经典结构变体
- 主神空间式：明确的主持者与积分体系，副本更像关卡挑战，成长线清晰——适合热血爽文向。
- 规则怪谈式：无明确主持者，规则来自怪谈本身，重点在解谜与求生，氛围阴郁——规则的精巧程度决定作品上限。
- 轮回解谜式：同一时空反复循环，靠试错积累信息破局——信息差管理是核心，每次循环必须给出增量信息。
- 生存竞赛式：多人同副本、淘汰制，博弈与人性拷问为主，规则相对简单、对手是真正的变量。

## 读者期待
- 规则公平可推演：读者拿着规则也能推演破法；主角的胜利来自对规则的深挖与巧妙运用，而非规则外开挂。
- 破解的智力快感：破局过程展示完整的推理链——如何发现暗规则、如何验证、如何利用漏洞，每一环都可复盘。
- 成长与副本同步：道具、积分与能力在副本中实际生效并受限制，成长看得见、用得上。
- 副本不重复：每个副本有新的规则类型与矛盾类型，换皮副本是弃读点。

## 常见坑
- 规则自相矛盾：副本规则前后冲突、漏洞百出——规则写进设定（00-设定/glossary.md 或世界规则文件）并随 continuity 核查。
- 金手指破坏公平：主角自带无敌道具/能力碾压一切副本——能力与道具限用途、限次数，公平是类型地基。
- 副本同质化：换地图不换规则——每个副本设计一个独有的规则核心与矛盾类型。
- 跨副本设定崩坏：道具上一副本强、这一副本失灵，兑换价格前后不一——成长体系成表管理、随稿更新。
- 循环无增量：轮回流重复无效循环，读者信息无增长——每轮循环必须贡献新信息或新变量。

## 文风与称谓惯例
- 冷静的解谜笔调：规则的呈现精确如说明书，推理过程条理分明；紧张感来自规则的压力而非修辞的嘶吼。
- 规则文本精确表述：明规则的措辞一字不差地呈现（漏洞往往藏在措辞里），引用规则时不得凭印象转述。
- 术语体系一致：副本、积分、道具、称号、惩罚等术语前后一致并记入 glossary；每个副本的专名遵循该副本世界的命名逻辑。
- 对白随副本世界切换：现代背景角色进古代副本，称谓与说话方式随副本调整——但主角的现代身份痕迹是天然看点，两者分寸按设定执行。

## 与其他 skill 的配合
- 设定阶段：总规则、道具成长体系写入 world.md 与 glossary.md，副本档案逐副本建档（规则、NPC、破局点）可放 00-设定/ 下专设文件；跨副本一致性随 continuity 追踪。
- 规则怪谈与 genre-horror 叠加：怪谈氛围、留白与安全阀节奏参考 genre-horror；冲突时以本 skill 的规则公平性为先。
- 大纲与正文阶段：副本节奏（进入→试探→危机→破局→结算）排入 novel-outlining；正文对照 writing-craft 执行钩子与信息差纪律，本 skill 负责规则自洽与破解链核查。
