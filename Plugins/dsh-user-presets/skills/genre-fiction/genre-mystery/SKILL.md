# 悬疑推理类型惯例（genre-mystery）

## 何时使用
- 开题判定作品类型为悬疑推理（含刑侦、罪案、解谜向悬疑），或混合类型中声明含悬疑元素时，全程加载本 skill。
- 谜题设计、线索排布与揭示节奏各阶段对照本 skill 检查；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 谜题设计：案件/谜题（凶案、失踪、失窃、怪事）开题即定「谜底」——先想清真相，再倒推线索；谜题要有解、答案要唯一或有限，机械降神是最大禁忌。
- 公平性：读者与解谜者信息对等——侦探所依据的线索必须全部提前呈现在文本中（或读者可合理推导），禁止结局突然亮出读者从未见过的关键证据。
- 线索管理：线索分三档——显性线索（明示）、暗示线索（写到了但容易被忽略）、误导线索（红鲱鱼）；红鲱鱼必须有独立存在的合理性，不能只为骗读者而设。
- 动机与手法：凶手动机、作案手法、时间线、不在场证明要环环相扣；社会派还要求动机有社会与人性深度，本格派要求手法有机械可行性。
- 解谜者设置：侦探/刑侦/记者/当事人视角不同，解谜路径也不同；解谜者的能力边界（权力、知识、时间）决定他能看到什么。

## 经典结构变体
- 本格推理：谜题优先、公平竞赛，读者可以挑战答案；手法与诡计是核心卖点，日常逻辑与物理可行性必须严格。
- 社会派：案件为壳、社会为核，动机与制度批判重于诡计；线索密度可略低，但人性逻辑必须严。
- 悬疑惊悚：无明确侦探，靠信息差与威胁悬念推进（「凶手是谁/下一个是谁」），真相揭示可分段递进。
- 倒叙推理/叙述性诡计：先给结果再解过程，或利用叙述视角本身设局——诡计要提前埋、事后可复盘，禁止纯靠隐瞒关键事实行骗。

## 读者期待
- 可解性：认真读的读者能推理出答案；答案揭晓后回看，所有线索各就各位。
- 伏线回收完整：每条线索、每个异常细节最终都有交代，无关线索可以少，但不可烂尾。
- 反转意外且合理：反转基于已呈现信息的重新解释，而非新信息空降；反转一次足矣，连环反转为反转而反转会耗尽信任。
- 推理过程的展示：解谜者如何排除错误可能、锁定真相，推理链完整可循。

## 常见坑
- 机械降神：结局靠读者从未见过的证据/巧合破案——线索必须前置，破案必须由已呈现信息支撑。
- 线索晚于真相：写着写着改真相，前面的线索对不上——真相开题定稿，写作中如需变更必须回头修订全部线索。
- 侦探光环：侦探看一眼就「直觉」破案、不展示推理——推理过程与排除法要写足。
- 动机薄弱：为诡计牺牲动机（高智商凶手为琐事杀人）——动机与手法同权重。
- 埋线不回收：满屏「异常细节」最后无交代——每条异常要么是线索要么是红鲱鱼，都要有下落。

## 文风与称谓惯例
- 叙述冷峻克制：以精确、克制的笔调呈现细节——时间、位置、物证、口供中的矛盾；悬念靠信息差的安排制造，不靠故弄玄虚的修辞。
- 细节的精确复现：线索的呈现要精确到可复盘（「左手第三个抽屉半开」），模糊的细节等于没有线索。
- 人物称谓与时间线一致：刑侦背景用职务称谓（警官/法医/队长），民间背景按身份；时间线、地点、物证编号前后一致，错乱即泄题。
- 血腥克制：命案描写服务于谜题（伤情、凶器、现场关系），不堆砌感官刺激（尺度红线见 规范-创作.md）。

## 与其他 skill 的配合
- 设定阶段：人物关系、时间线与案件要素写入 story-bible 体系（timeline.md 记时间线、characters/ 记动机），线索台账可作为 03-修订/continuity-log.md 的专项清单追踪。
- 大纲与正文阶段：线索揭示节奏排入 novel-outlining（提问→延宕→部分揭示→再提问）；正文对照 writing-craft 执行信息差与钩子纪律（悬念与信息差一节），本 skill 负责公平性与伏线回收核查。
- 涉及现实刑侦/法医/法律细节时，按 research-materials 规范考据并注明来源。
