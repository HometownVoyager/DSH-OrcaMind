# 末世废土类型惯例（genre-postapoc）

## 何时使用
- 开题判定作品类型为末世废土（病毒末日、核废土、天灾末日、文明重建），或混合类型中声明含末世元素时，全程加载本 skill。
- 崩坏设定、生存逻辑与人性博弈各阶段对照本 skill 检查；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 崩坏原因与推演：灾难的成因（病毒、核战、天灾、技术失控）决定末日形态——成因定范围（全球/局部）、定速度（骤变/渐进）、定幸存者结构；崩坏如何发生、社会如何停摆，要写得出过程。
- 生存秩序：物资（食物、饮水、药品、能源）的存量、补给与消耗是硬约束，医疗退化的后果（小伤致死）要真实；幸存者如何重组秩序——聚居地规则、货币（以物易物）、武装与暴力垄断。
- 人性博弈：极端稀缺下的人性——互助与掠夺、秩序与丛林、希望与绝望的反复拉扯；道德选择要有真实代价，不贴善恶标签。
- 废土生态：灾后的环境、变异生物、废墟与遗物构成新生态——新世界的「常识」与旧世界残迹的对照是类型气质所在。
- 主题落点：末日的题眼是「文明是什么」——重建的可能、代价与方向，或秩序崩塌后人还剩什么；爽点服务于这个追问。

## 经典结构变体
- 病毒末日：病原体导致文明停摆，重点是隔离、感染规则与幸存者社会的重组；感染规则要自洽（传播、潜伏、变异、免疫）。
- 核废土：辐射、污染与废墟城市，重点是环境危险、资源分布与战后秩序；辐射的物理后果要基本可信。
- 天灾末日：气候/地质/天体灾变，重点是人类在自然力量前的脆弱与适应；灾难机制要有科学下限（不必精确，但不过分离谱）。
- 文明重建流：末日之后如何从零重建（农业、教育、制度），成长感与希望感强，适合长篇；重建的技术细节要可信。
- 末日求生游戏：生存挑战结构（签到、任务、基地经营）与无限流相邻——若副本/系统结构为主，改按 genre-infinite 的规则纪律执行。

## 读者期待
- 末日逻辑自洽：灾难的机制、资源的约束、秩序的崩解与重建都经得起推演；读者用常识推不出矛盾。
- 生存细节真实：食物、饮水、药品、燃料的具体来源与消耗；小伤怎么处理、夜宿怎么安排——细节真实才有代入感。
- 人性拷问有分量：极端情境下的选择有代价、有后果、有回响，不喊口号也不黑深残。
- 角色成长可信：从旧世界思维到末世生存者的转变有过程、有代价。

## 常见坑
- 物资无限：主角凭空有粮有药有弹药，经济逻辑缺失——建立物资台账，来源与消耗可查（记入设定或随稿追踪）。
- 道德极端化：圣母到底或黑化到底，人物扁平成口号——选择要有代价，人物要有动摇与后悔。
- 末日设定前后矛盾：感染规则、灾变范围、辐射后果忽大忽小——崩坏机制开题定稿并随 continuity 核查。
- 配角当消耗品：配角只为送死而来——幸存者群像要有人物价值（技能、关系、立场），死亡要有重量。
- 只有末世没有废土：灾难一过直接进入普通冒险——把灾后生态（变异、废墟、新秩序）写实，它才是类型的质感。

## 文风与称谓惯例
- 冷硬写实笔调：克制、精确、不煽情——灾难的残酷靠细节呈现（缺水的嘴唇、变质的食物），不靠形容词；恐惧与绝望按 genre-horror 的氛围纪律呈现时仍保持写实底子。
- 生存术语体系：避难所、搜索队、净化站、聚居地等新秩序词汇前后一致并记入 glossary；旧世界遗物名称（品牌、地名）作为时代符号使用。
- 对白贴生存状态：语言随秩序崩塌而变化——粗粝、直接、信息密度高，幸存者不聊闲天；但保持完整句子的句式纪律。
- 暴力描写克制且服务于逻辑：冲突写清代价与后果（弹药消耗、伤员处理），不堆砌血腥（尺度红线见 规范-创作.md）。

## 与其他 skill 的配合
- 设定阶段：崩坏机制、感染/辐射规则、物资台账写入 world.md 与 glossary.md，聚居地与势力写入 factions.md；物资与时间线随 continuity 追踪。
- 生存游戏/系统流与 genre-infinite 叠加：副本/任务结构按 genre-infinite 的规则公平纪律执行；本 skill 管末世生态与生存逻辑。
- 大纲与正文阶段：灾变节点、秩序重建节点排入 novel-outlining；正文对照 writing-craft 执行场景经济学与钩子纪律，本 skill 负责末世逻辑与人性博弈核查。
