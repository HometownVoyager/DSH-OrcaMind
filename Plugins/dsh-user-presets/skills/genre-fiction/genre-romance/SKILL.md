# 恋爱类型惯例（genre-romance）

## 何时使用
- 开题判定作品类型为恋爱，或混合类型中声明含恋爱元素（如玄幻+恋爱）时，全程加载本 skill。
- 关系线设计、大纲排布与正文写作各阶段对照本 skill 检查节拍、配比与禁忌；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 关系类型：先婚后爱、青梅竹马、欢喜冤家、契约、救赎、破镜重圆等——开题即与用户确认关系类型与结局方向（HE/BE/开放），这是情感线的顶层设定。
- 人物情感需求与障碍：写清两人各自想要什么、怕什么、缺什么——情感需求决定吸引的原因，内在障碍决定冲突的深度；两人互相满足对方的缺口才叫双向奔赴。
- 情感驱动情节：关系的变化（靠近、误解、裂痕、和解、确认）本身就是事件，情节因情感变化而推进，而不是感情戏与事件两张皮。

## 经典结构变体
- 欢喜冤家：从对抗到心动，转机必须有可信的事件支撑（共同经历/重新认识），不是突然改口。
- 救赎型：一方把另一方从低谷拉出，注意救赎是相互的——被救者必须反哺救赎者，否则关系失衡。
- 双向暗恋：信息差是核心张力，两人的误判各有依据；揭开时机与代价要计算好。
- 追妻/追夫：先虐后甜，虐点必须来自真实伤害而非无谓刁难，追的部分要有实质改变与补偿。
- 破镜重圆：分开的原因要够重、和解要够实，重圆的依据是新的事实而非旧情复燃一句话。
- 配比形态：纯恋爱（感情线即主线）或恋爱副线（混合类型中从属主类型主线）；配比与主次由用户拍板。

## 读者期待
- 关系推进节拍感：心动→试探→升温→危机→确认，每步都有事件支撑，进展看得见、等得起；迟迟不推进或一夜突进都失速。
- 糖与虐的配比与兑现：糖分要真实（细节、行动、独一份的在意），虐点要合理（有因有果、有代价）；只发糖不推进或只虐不甜都消耗耐心。
- 双向奔赴的合理性：两人的付出与改变都要让读者看见，单向付出是雷点。
- 配角的独立人格：配角有自己的生活与动机，不降智、不当传声筒。

## 常见坑
- 误会硬造：一句话能说清却拖十章——误会必须有不可言说的真实障碍（自尊、责任、信息不对等）支撑，且不重复使用同一机制。
- 和解廉价：大错小赔、虐过即甜——和解必须与伤害对等，有道歉、有改变、有补偿。
- 工具人配角：配角只负责制造误会或助攻——给配角独立动机，助攻也要有他自己的理由。
- 强行降智：为推进剧情让角色做出不符合人格的蠢事——先查人物设定再写冲突。
- 确认后乏力：关系确认即剧情枯竭——确认不是终点，外部威胁、共同目标、关系内部的成长课题要提前备好。
- 情感线与主线脱节：混合类型中感情戏与主线各演各的——感情节点要与主线节点咬合（患难见真情、决裂成主线转折）。

## 文风与称谓惯例
- 细腻心理描写：情绪通过行为细节承载（手的动作、语速、回避的眼神），禁止情绪标签直给（「我很生气」）；心理活动与唤醒度纪律见 writing-craft。
- 称谓变化体现关系递进：连名带姓→名字→专属称呼，每一步变化都是一个关系节点；越界或回退的称呼本身可以讲故事。
- 情话克制：拒绝油腻情话与网络烂梗；深情藏在具体的行为与细节里，金句稀缺（见 writing-craft 金句克制）。
- 亲密戏按用户尺度的红线执行：开题确认尺度边界并写入 规范-创作.md 的红线节，正文不得越界。

## 与其他 skill 的配合
- 设定阶段与 story-bible 配合：两人的情感需求、障碍与关系变化方向写入 characters/ 与 relationships.md；混合类型时与对应 genre skill 并行加载，主类型的结构惯例主导。
- 大纲与正文阶段：关系节拍排入 novel-outlining 的章节功能表（每章的情感节奏一栏）；正文对照 writing-craft 执行潜台词与唤醒度纪律，本 skill 负责节拍、配比与禁忌核查。
