# 科幻类型惯例（genre-scifi）

## 何时使用
- 开题判定作品类型为科幻，或混合类型中声明含科幻元素时，全程加载本 skill。
- 设定奇点确认、推演链设计与正文写作各阶段对照本 skill 检查推演纪律与硬/软科幻的处理差异；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 设定奇点：开题先确认「一个什么变了」——一个核心科技或设定（意识上传、可控核聚变、外星接触、时间旅行……），它是整个故事的起点；奇点要新（老点子要有新角度），且一句话能说清。
- 推演链：从奇点出发推演连锁变化——技术层（还能做什么）→ 社会层（谁受益谁受损、制度怎么变）→ 伦理层（人怎么看待自己与他人）→ 日常层（普通人生活变成什么样）；每个层面都要想，故事只讲最要紧的几条。
- 技术代价：每项技术写明代价与限制（能耗、副作用、准入条件、不可逆后果），代价是冲突的来源——没有代价的技术会吞噬一切戏剧性。
- 技术与社会的互动：制度、经济、伦理随技术而变，技术又受社会反塑；科幻的价值在「推演」，不在「特效清单」。

## 经典结构变体
- 硬科幻：技术设定严格基于真实科学并写明推演过程，数字与原理可查证；写错了会被读者指摘，拿不准的必须按 research-materials 考据。
- 软科幻：借科幻外壳探讨社会、哲学与人性，技术可一笔带过但外壳自洽；重心在思想实验的完整呈现。
- 太空歌剧：宏大尺度、政治与战争，科技密度低、格局密度高；注意别写成中世纪宫廷换皮。
- 赛博朋克：技术垄断与底层生态的对峙，基调阴郁；奇点往往是小而深的一项技术（义体、脑机）而非宇宙级设定。
- 末世/废土：已独立为 genre-postapoc skill——末世/废土题材请加载该 skill，本节不再覆盖。
- 时间旅行：必须提前确立时间模型（单线/多线/平行），并严格遵守——时间悖论的处理方式开题即定并落盘。

## 读者期待
- 设定自洽与推演逻辑：读者顺着奇点推不出矛盾；主角的破局来自推演的缝隙而非新设定空降。
- 奇点新颖性：开篇即给出「没见过但成立」的核心设定；老题材（克隆、AI 觉醒）必须提供新角度。
- 思想实验深度：奇点的后果被认真对待——技术如何改变人的处境与选择，而不是只在背景里发光。
- 硬科幻的技术准确性：硬科幻的术语、数字、原理经得起推敲；区分硬/软后按各自标准执行，不挂硬科幻之名行软科幻之实。

## 常见坑
- 硬科幻失实：设定违背基本物理却自称硬科幻——要么考据到位，要么降格为软科幻外壳并自洽。
- 技术万能化：万能修复剂、万能 AI、万能能源兜底一切——每项技术限用途、限代价，绝不让技术代替人物解决冲突。
- 奇点缺乏社会推演：技术天翻地覆、社会纹丝不动——奇点必须渗进制度、经济与普通人的日常。
- 术语堆砌：术语不加解释连排，读者弃读——术语首次出现即在上下文给出可理解的说明，非必要不造词。
- 老点子无新角度：克隆人、缸中之脑、AI 觉醒直接复用经典套路——先问「我的版本新在哪」。
- 时间旅行悖论写崩：模型未定就开始写——时间模型开题定稿并写入 00-设定/world.md，全程不违背。

## 文风与称谓惯例
- 叙述克制理性：以精确、冷静的笔调写设定与推演，数字、术语、单位准确；情感张力反而靠克制衬托（对比见 writing-craft 氛围与唤醒度）。
- 硬/软密度差异：硬科幻给技术细节与推演过程（读者要看「怎么做到」），软科幻给人文冲突与后果（读者要看「代价是什么」）；密度选错即风格错位。
- 术语必要才用：每一个术语都承担表意功能，首次出现给解释；机构名、技术名、纪元名前后一致并记入 glossary。
- 对白随时代与身份：未来人的说话方式随技术与社会而变（不滥用网络热词，也不装腔作势），专有名词之外避免生造。

## 与其他 skill 的配合
- 设定阶段与 story-bible 配合：奇点、推演链与技术代价写入 world.md；时间模型（如有）开题即定稿；术语记入 glossary.md。
- 考据：硬科幻的科学技术背景按 research-materials 规范联网查证并注明来源，区分事实与创作设定。
- 大纲与正文阶段：推演揭示的节奏排入 novel-outlining（提问→延宕→部分揭示→再提问）；正文对照 writing-craft 执行场景经济学与钩子纪律，本 skill 负责推演自洽与硬/软密度核查。
