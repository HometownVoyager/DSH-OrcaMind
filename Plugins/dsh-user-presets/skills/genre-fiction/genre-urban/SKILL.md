# 都市现实类型惯例（genre-urban）

## 何时使用
- 开题判定作品类型为都市现实（都市情感、职场、年代文、都市生活，含都市异能等现实背景变体），或混合类型中声明以现实都市为背景时，全程加载本 skill。
- 背景设定、时代细节与类型化处理各阶段对照本 skill 检查；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 现实背景纪律：故事发生在可辨认的现实社会——时代背景（当代/九十年代/改革开放前）决定制度、器物、通讯、观念与钱物尺度；时代细节必须与背景一致，这是本类型的第一纪律。
- 职业与行业真实性：角色职业（医生/律师/程序员/公务员/生意人）的日常、规则与困境要真实——职业决定人物的时间、圈子、收入与说话方式；拿不准的行业细节按 research-materials 考据。
- 社会规则：房价、户口、教育、职场晋升、人情世故——现实规则是冲突与爽点的土壤；爽点可以理想化，但不能违反读者公认的基本规则。
- 类型化处理：都市情感重关系推演，职场文重成长与博弈，年代文重时代质感与命运感，都市异能重「超凡能力撞进现实秩序」的错位——开题即定子类型与基调。

## 经典结构变体
- 都市情感：现代人的亲密关系（婚恋、家庭、成年人的选择），情感逻辑要贴现实——参考 genre-romance 的节拍纪律，但情感障碍更多来自现实（工作、家庭、经济）而非误会。
- 职场成长：新人到骨干/高管的进阶，核心是能力成长、人际博弈与行业洞察；升迁逻辑要真实，不靠金手指一步登天。
- 年代文：重生/回溯到过去年代，卖点是时代质感与命运重塑；历史节点、物价、生活细节必须准确。
- 都市异能：异能/系统进入现实都市，核心是超凡与现实的错位感——异能必须有限、有代价，并遵守现实社会规则（瞒不住怎么办、监管怎么办），而非把现实踩在脚下。

## 读者期待
- 现实质感与代入感：职业细节、生活细节、钱物尺度真实可信，读者觉得「这就是我认识的世界」。
- 时代细节准确：年代文的时间点、物价、事件、物品与语言习惯经得起推敲，穿帮即出戏。
- 爽点不破坏现实逻辑：金手指可以存在，但必须在现实规则内生效（有代价、有制约、有解释），碾压式的「全世界都是笨蛋」是毒点。
- 人物的现实困境：角色的烦恼来自真实的生活结构（房贷、职场、家庭），而不是为虐而虐的降智设计。

## 常见坑
- 时代错误：年代文的物价、通讯、称谓、流行语穿越——动笔前列一张时代要素对照表并写进 00-设定/。
- 职业失真：把医生写成「随叫随到的全科超人」、把程序员写成「秒黑所有系统」——行业细节按 research-materials 考据。
- 现实逻辑断裂：角色经济状况忽好忽坏、社会规则说没就没——收入、住房、家庭关系等现实锚点开题定稿并贯彻。
- 异能万能化：都市异能用超能力解决一切现实问题——异能限用途、限代价，现实规则优先。
- 以今代古（年代文）：用当代观念与网络词写过去的人——时代观念与语言习惯随背景切换。

## 文风与称谓惯例
- 现代汉语自然对白：对白像现实里的人说话——职业圈有职业圈的话术，地域有地域的口吻；避免书面腔硬塞进对白。
- 职业术语准确且必要：行业术语用在行内交流的场景，首次出现即有语境支撑，不堆砌不炫耀。
- 时代用语贴切：年代文用当时的语言习惯与称谓（同志/师傅/先生），现代网络热词只属于当代角色。
- 情感表达克制：现实题材的情感靠细节与行动（写满的便签、保留的习惯），不靠情话轰炸（见 writing-craft 潜台词与金句克制）。

## 与其他 skill 的配合
- 设定阶段：时代要素对照表、职业设定与人物现实锚点写入 00-设定/（world.md 记时代背景，characters/ 记职业与现实处境）；年代文的时间线按 timeline.md 管理。
- 都市情感与 genre-romance 叠加：关系节拍参考 genre-romance，情感障碍替换为现实结构性问题；两者冲突时以本 skill 的现实背景纪律为先。
- 大纲与正文阶段：职场博弈、现实冲突的节奏排入 novel-outlining；正文对照 writing-craft 执行场景经济学与汉语语感纪律，本 skill 负责时代与职业真实性核查。
