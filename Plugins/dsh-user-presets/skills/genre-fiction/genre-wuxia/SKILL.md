# 武侠类型惯例（genre-wuxia）

## 何时使用
- 开题判定作品类型为武侠，或混合类型中声明含武侠元素时，全程加载本 skill。
- 设定集、大纲与正文各阶段对照本 skill 检查武学体系、江湖格局与侠义主题是否到位；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 武学体系：内功、招式、兵器、轻功各自成体系且互相制约——内功定根基（谁的内力深厚、属性如何），招式定打法（克制关系、绝招底牌），轻功定机动（追击、逃遁、场面调度）；体系自洽、可推演，境界划分要能解释实力差距。
- 江湖门派与武林格局：名门正派、邪道魔教、世家、官府、镖局、丐帮等构成武林生态，写清各派的武功路数、立场与恩怨史；武林有武林的秩序（规矩、名帖、武林大会），官府有官府的秩序，两者如何交集是经典张力来源。
- 侠义主题：武侠的核心是「侠」——快意恩仇、锄强扶弱、重诺轻生、身不由己；主角的抉择要落在侠义与利害的冲突上，武功只是手段，侠义才是题眼。
- 恩怨结构：师门恩怨、杀父之仇、情仇、夺宝之争——恩怨要有因果链，仇要结得实、报得有代价。

## 经典结构变体
- 复仇流：灭门/夺宝/陷害开局，主角练功寻仇，真相在报仇路上层层反转（仇人可能是恩人）；注意复仇完成后的落点（放下或成空）。
- 门派兴衰流：以门派为单位写兴衰——收徒、立派、内斗、外敌，群像与传承感强。
- 朝堂与江湖：庙堂之高与江湖之远互相卷入，侠以武犯禁与官府缉拿的博弈。
- 夺宝/秘籍之争：一件宝物或秘籍搅动武林，多方势力逐鹿，核心是人心与代价。
- 浪子游侠流：主角游历江湖、路见不平，单元事件串联成长线。

## 读者期待
- 武学体系自洽：境界、内功、招式前后一致，胜负逻辑让读者信服——输赢看的是武学理解与临场运用，而非新招式空降。
- 侠义抉择的戏剧性：主角在「该做的」与「该得的」之间抉择，读者要看的是代价与坚持，不是无脑行侠。
- 打斗的招式感：打斗要有招式、有变化、有克制关系与胜负手，不写成「两人对轰、主角赢了」。
- 江湖人情味：师门情、兄弟义、红颜知己，情感线自然生长于恩怨之间。

## 常见坑
- 武力通胀：前期高手后期贬值、境界无限拔高——用体系天花板与「内力有极限、招式有相克」锁死膨胀。
- 正邪脸谱化：名门必伪君子、魔教必真性情——正邪都要有各自的行事逻辑与内部差异。
- 套路复仇：为复仇而复仇、仇人纯工具——恩怨要有真实动机与反转空间。
- 江湖与官府割裂：江湖仇杀惊天动地、官府全程隐身——写明两套秩序的互动规则。
- 打斗写虚：全程「刀光剑影」「身形一闪」无实招——招式、距离、兵器、地形要落到具体。

## 文风与称谓惯例
- 武侠腔半文半白：叙事可带说书气与文白相间的节奏，对白自然上口，不为古而古、不拗口。
- 江湖称谓体系化：大侠、前辈、师门辈分（师叔/师兄）、官职头衔前后一致；角色间称呼随关系与场合变化，错称是连续性事故。
- 招式名成体系：招式命名有门派风格（如少林多「罗汉」、武当多「太极」），同一门派的命名逻辑统一，记入 glossary。
- 避免现代网络口语：对白不得出现现代网络热词；穿越/系统设定除外且需世界观明确允许。

## 与其他 skill 的配合
- 设定阶段与 story-bible 配合：武学体系与境界写入 world.md 与 glossary.md，门派势力写入 factions.md，恩怨关系写入 relationships.md。
- 大纲与正文阶段：恩仇节点与比武高潮排入 novel-outlining 章节功能表；打斗场面按场景经济学与唤醒度纪律执行（见 writing-craft），本 skill 负责武学自洽与侠义主题核查。
