# 仙侠类型惯例（genre-xianxia）

## 何时使用
- 开题判定作品类型为仙侠（区别于武侠：核心是修仙问道、长生飞升，而非江湖武功），或混合类型中声明含仙侠元素时，全程加载本 skill。
- 设定集、大纲与正文各阶段对照本 skill 检查境界体系、因果逻辑与仙道主题；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 修仙境界体系：炼气、筑基、金丹、元婴、化神等境界划分，写明每境的特征、寿元、手段与突破条件；境界之间实力差距量化且前后一致，境界表一经落盘即为已确认设定。
- 机缘与代价：功法、法宝、灵药、秘境机缘必须与危险对等——机缘是推动力，代价（反噬、心魔、因果、寿元）是约束力；无代价的机缘是通货膨胀。
- 因果与天道：仙侠世界的底层规则——因果报应、天道循环、逆天而行必有劫；主角的每次大造化都应留下因果账，后期兑现。
- 宗门仙道生态：宗门传承、师徒体系、正道魔道仙门、散修与凡俗世界的层级关系；飞升之后的世界（上界/仙界）若涉及，开题即定其规则。
- 问道主题：修仙不止变强——长生、超脱、执念与舍弃的抉择构成主题深度；主角修仙的「初心」随境界变化而变化，是人物弧线的核心。

## 经典结构变体
- 凡人流：出身凡俗、资质平庸，靠算计、谨慎与机缘步步登天，核心是「凡人凭什么赢」的智力快感。
- 宗门流：拜师入门、宗门内成长与外敌对抗，传承感与群像感强。
- 仙魔之争：正道魔道两立，主角游走其间或出身魔道，考验立场与道心。
- 转世重生流：前世大能或凡人重生，携记忆改命，爽点在于预知与翻盘；注意重生优势必须有限度。
- 问道求索流：以「道」为主线（剑道、丹道、阵道……），专业纵深代替境界攀爬。

## 读者期待
- 境界表清晰可查：境界高低、寿元、手段一目了然，含糊的等级是大忌。
- 机缘与代价对等：主角的收获都有相应的付出，读者信服「他配得上这份机缘」。
- 因果兑现：前期埋的因果、誓言、心魔，后期必须兑现或清算，不作废、不吃书。
- 哲思深度：长生的代价、超脱的代价、执念与放下的辩证——读者期待境界之上还有「道」的思考。

## 常见坑
- 境界通货膨胀：境界无限叠加、前期强者贬值——境界表设定天花板并锁死晋升代价。
- 奇遇无代价：走到哪捡到哪、法宝功法批发——机缘与危险、因果严格对等。
- 修炼与人性脱节：境界涨了、心性没变，人物空心化——每境配一个人物课题（心魔/执念/取舍）。
- 飞升即烂尾：升到顶发现无以为继——上界规则开题即定，或把结局落在「道」而非「境」上。
- 术语堆砌：丹方、功法、法宝名不加解释连排——术语首次出现即在上下文给出可理解的说明。

## 文风与称谓惯例
- 仙侠文风飘逸或古朴：可带道家语境（道号、法号、因果、劫数），叙述克制庄重，禁现代网络口语。
- 称谓体系化：道号、法号、师门辈分（师尊、师叔祖）、修为尊称（前辈、道友）前后一致；称呼随境界与关系变化，错称是连续性事故。
- 术语成体系：功法、法宝、灵药、洞府的命名遵循统一逻辑并记入 glossary；量词与品级（如法宝分品、丹药分阶）设定后贯彻到底。
- 对白随身份：凡俗人与修仙者的说话方式有别，长寿修士的生死观通过言行自然流露，不靠旁白贴标签。

## 与其他 skill 的配合
- 设定阶段与 story-bible 配合：境界表、机缘代价与因果账写入 world.md 与 glossary.md，宗门写入 factions.md；因果债单独登记并随 continuity 追踪。
- 大纲与正文阶段：机缘/代价节点与因果兑现点排入 novel-outlining；正文对照 writing-craft 执行场景经济学与钩子纪律，本 skill 负责境界自洽与因果逻辑核查。
