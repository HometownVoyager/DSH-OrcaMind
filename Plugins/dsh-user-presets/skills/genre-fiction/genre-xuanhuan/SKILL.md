# 玄幻类型惯例（genre-xuanhuan）

## 何时使用
- 开题判定作品类型为玄幻，或混合类型中声明含玄幻元素（如玄幻+恋爱，且玄幻为主或次类型）时，全程加载本 skill。
- 设定集、大纲与正文各阶段对照本 skill 检查类型要素是否到位、类型惯例是否被违背；本 skill 管类型惯例，写作技法一律与 writing-craft 叠加使用。

## 题材要素
- 修炼体系：力量来源（灵气/武魂/道法/血脉等）、修炼路径与境界划分必须自洽且可推演——读者要能顺着规则推知某一境界能做什么、不能做什么；体系一经落盘即为已确认设定，后续不得随意增补或吃书。
- 境界与代价：每个境界写明突破条件、瓶颈与代价（资源、心魔、天劫、寿命、走火入魔风险），境界之间的实力差距量化（如「差一大境界不可越级」要能解释为何）；代价是体系可信度的来源，无代价的升级是数值膨胀。
- 宗门势力：宗门、家族、王朝、散修与秘境构成势力生态，写清各势力的立场、利益与关系网；主角的成长不止是境界爬升，还要在势力博弈中站住位置。
- 成长线：主角的成长弧线与体系的关系——资源获取、机缘与危险并存，升级节奏服从爽点节奏与主线。

## 经典结构变体
- 废柴逆袭流：低起点高潜力，开篇受压、逐步翻盘，核心是「打脸兑现」的延迟满足。
- 天才流：高起点、强敌环绕，压力来自同代竞争与更高层级的碾压，爽点在以少胜多与越级。
- 稳健苟道流：主角刻意藏拙、压制境界，靠信息差与后手翻盘，爽点在「扮猪吃虎」的算计。
- 诸天/位面游历：副本式世界切换，每个位面一个完整小循环，注意跨位面设定的一致性。
- 宗门种田/势力经营：主角建设宗门或势力，升级与经营双线，节奏比纯升级流更慢但粘性更强。

## 读者期待
- 清晰的境界等级表：读者随时可查证境界高低与实力对比，含糊的等级是最大败笔。
- 升级节奏与回报感：升级要有铺垫、有代价、有回报场景，突破要写足仪式感与获得感。
- 爽点密度：打脸、碾压、机缘兑现要有节奏地分布，连续多章无爽点即失速；爽点必须自洽，不能靠削弱敌人制造。
- 体系自洽：前期埋的力量规则到后期仍成立；境界天花板与战力上限开篇就应有大致框架，避免后期崩坏。

## 常见坑
- 境界通货膨胀：后期随手毁天灭地、前期强者贬值为炮灰——用境界天花板与代价机制提前锁死上限。
- 配角工具化：配角只当垫脚石，用完即弃——给重要配角独立动机与成长线。
- 换地图换皮：同构的「打怪—升级—换地图」无限循环——每张地图要有新的矛盾类型，而不只是更强的怪。
- 金手指无代价无上限：外挂必须有边界与代价（限制、冷却、反噬），否则冲突失去意义。
- 设定吃书：修炼体系、势力关系与已确认设定冲突——一律按 continuity 纪律先请用户裁决。
- 感情线突兀：感情线脱离主线硬插——混合类型按主类型节奏排布，非混合类型感情线从属主线。

## 文风与称谓惯例
- 半文半白但不拗口：可带修真腔（「道友」「长老」「宗门」「洞府」），句子仍要通顺自然，不得为古而古。
- 称谓体系化：境界名、辈分、宗门职衔前后一致；角色间的称呼随境界与关系变化（如平辈称道友、晚辈称师侄），错称是连续性事故。
- 术语自造要有解释：新境界、新功法、新地名首次出现即在上下文给出可理解的说明，不堆砌不解释。
- 避免现代网络口语直接穿越：除非世界观明确允许（如穿越者主角），角色对白不得出现现代网络热词。

## 与其他 skill 的配合
- 设定阶段与 story-bible 配合：修炼体系、境界表、宗门势力写入 00-设定/（glossary.md 记术语、factions.md 记势力、world.md 记规则与代价）。
- 大纲与正文阶段：升级节点、爽点节奏排入 novel-outlining 的章节功能表；正文对照 writing-craft 执行场景经济学、钩子与唤醒度纪律，本 skill 负责其中的类型要素核查。
