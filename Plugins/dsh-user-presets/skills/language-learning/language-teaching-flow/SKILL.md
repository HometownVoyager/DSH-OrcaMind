# 语言教学流程（language-teaching-flow）

> 母本：science-teaching-flow（science-learning 预设），按语言域改造：讲授推导链改为目标语输入-输出训练，数值合理易运算改为真实语料 + CEFR 难度分级，LaTeX 输出改为目标语注音/音标/例句格式。默认英语、CEFR 标尺；换语种时本流程不变，仅替换教材与语料来源、按目标语调整标音格式。

## 何时使用
- 每次「语言学习」会话开始时：先总览工作区，再加载本 skill，按本规范建立或读取学习文档、执行教学流程。
- 制定总学习计划、开启新阶段、组织阶段测试或结课考核、登记重难点与错题、维护词汇本与语法笔记时，参考对应章节。
- 学习者明确应试目标（雅思/托福/四六级/Cambridge 序列等）时，加读「应试模式接口」一节。

## 学习文档体系
所有学习管理文档均为 Markdown，位于工作区根目录，按用途分文件夹存放：

```
<工作区根>/
├── README.md                  # 学习总览：语种/当前级别/目标/阶段划分/当前状态/下一步（最先创建，每轮先读）
├── 学习计划/
│   ├── 总学习计划.md          # 语种、级别目标、内容范围、阶段划分与测试安排
│   ├── 阶段计划-NN-技能模块.md  # 每阶段一份：目标技能（听说读写）、词汇/语法范围、训练与测试安排（NN 为两位序号）
│   └── 当前学习进度.md        # 唯一的进度文档：当前状态、测试记录、下一步
├── 词汇本/                    # 按主题或级别分档（如 词汇本/A2-日常饮食.md），每条含目标语例句与间隔复习标记
├── 语法笔记/                  # 语法点讲解 + 目标语例句（一档一个语法点或一组近义结构）
├── 练习/                      # 听/说/读/写分档，注明输入或输出训练与所属阶段
├── 测试题目/
│   ├── 阶段测试-NN-技能模块.md  # 每阶段结束时的综合测试题集（四技能覆盖）
│   └── 结课考核.md            # 全部阶段完成后的综合性结课考核
├── 重难点/
│   └── 重难点-NN-技能模块.md    # 每阶段一份：难点剖析、补充讲解与再练安排
├── 常错题/
│   └── 错题本.md              # 追加式错题记录（见「错题本纪律」）
└── 参考资料/                  # 语料与教材摘录，每份注明来源（教材章节/URL/出处）
```

纪律：
- 缺失的文档创建，已有的文档一律保留：不删除、不覆盖、不改写历史记录。
- 阶段计划、阶段测试与重难点文档在该阶段完成后继续保留，作为学习档案。
- 进度文档与错题本的每次更新采用追加方式：在文末添加带日期的变更记录，保留完整历史。
- README.md 不存在时，先按本 skill 的模板创建 README 与上述目录骨架（照实填写已知信息，未知项标注「待确认」），再展开教学；不先建总览就授课属于流程违规。
- 若工作区已有用户自建的文档（其他命名/位置），沿用用户的结构，不要重复创建或迁移；但根目录 README.md 仍应补建为总览入口。
- 开工第一步先执行开工规范检查并落盘 `规范-语言学习.md`（落在工作区根目录、不进项目目录内部）：学习者自备要求完整则直接采用，缺失或冲突先与学习者确认后再搭骨架；此后每轮检查与产出都以它为唯一规范事实源。

## README.md 结构
- 语种与材料来源（工作区中的文件/教材；无固定教材时注明语料来源约定）
- 学习者当前级别与目标级别（CEFR 或等价标尺，水平摸底后与学习者确认填写）
- 学习目标（通用提升 / 应试——应试时登记目标考试、分数/等级与考试日期）
- 阶段划分总览：每阶段一行（阶段号、技能模块、状态——未开始/进行中/已掌握/已测试通过/已结课）
- 当前状态与下一步（一两句，与 当前学习进度.md 保持一致，此处置于总览层）
- 指引：进度细节、测试记录见 学习计划/当前学习进度.md；词汇见 词汇本/；语法见 语法笔记/；练习见 练习/；测试题集见 测试题目/；错题见 常错题/错题本.md；难点见 重难点/；语料与教材摘录见 参考资料/。

每轮会话先读 README.md 与 当前学习进度.md 接续进度；阶段状态变化或确认掌握后同步更新两者。

## 总学习计划.md 结构
- 语种与材料来源（工作区中的文件/教材）
- 当前级别与目标级别（CEFR 或等价标尺；水平摸底依据简述）
- 学习目标（通用提升 / 应试模式说明）
- 学习内容范围：词汇量目标与主题范围、语法点清单、四技能目标
- 阶段划分：每阶段的技能模块、词汇/语法范围、预计课时
- 测试安排：每阶段一次综合测试 + 全部阶段后的结课考核

## 阶段计划-NN-技能模块.md 结构
- 阶段目标（技能目标 + 对应 CEFR 能力描述，如「能就日常话题进行简单交流，对应 A2 口语描述」）
- 词汇范围（主题与数量）与语法点清单
- 输入训练安排（听/读材料来源与量）与输出训练安排（说/写任务类型与反馈方式）
- 间隔复习安排（新词复现节奏、旧词汇与语法点重现安排）
- 阶段测试安排（测试题写入 测试题目/阶段测试-NN-技能模块.md）

## 词汇本纪律（词汇本/）
- 条目格式（一条一词，字段齐全）：目标语拼写 + 音标/注音 + 词性 + 释义（学习者所用语言）+ 目标语例句（附译文）+ 登记日期 + 间隔复习标记（下次复现日期）+ 掌握状态（未掌握/复现中/已掌握）。
- 按主题或级别分档存放（如 A2-日常饮食.md），新词随手登记，不在对话里口头带过不留档。
- 间隔复习节奏（缺省，可按学习者情况调整）：登记当天 → 第 2 天 → 第 7 天 → 第 21 天；每次复现在新课输入、练习或快速检测中主动重现，复现通过才推进掌握状态。
- 已到复现点的词汇优先安排；积压超过 20 条时，当节先安排集中复现再进新内容。

## 语法笔记规范（语法笔记/）
- 每个语法点按 形式（form）→ 意义（meaning）→ 用法（use）三要素组织：结构式与变形规则、表达的意义与语用功能、典型使用场景与限制。
- 例句不少于 3 条，含至少 1 条典型错例对比（错误形式 + 修正 + 错因一句）；注明来源，自拟例句如实标注「自拟」。
- 与词汇本联动：例句优先复用已登记词汇；讲解新语法点时同步登记未收录的生词。

## 教学循环（每节课内）
1. 课前回顾：复现到期的词汇（间隔复习标记）与上次课的语法点——用 ask_user_question 以选择题快速检测；未通过者先补讲再进新内容。
2. 输入呈现：给出真实语料（短对话、短文、听力转写、例段），注明来源；先让学习者接触目标语原文，不先灌规则。
3. 引导归纳：用提问引导学习者从语料中自己归纳语言规律（形式、意义、用法），根据作答即时反馈、纠正误区；归纳结果落 语法笔记/ 或 词汇本/ 登记。
4. 例句演示与仿写：演示典型例句的完整分析（结构拆解 + 释义 + 使用场景），随后给仿写任务让学习者产出。
5. 穿插练习：讲解过程中出 2–5 道与当前知识点匹配的练习（按「练习与测试设计规范」），四技能轮换，即时批改讲解；需要快速检验掌握情况时用 ask_user_question 以选择题形式提问，判断题（true/false question）作为「True / False」二选一的选择题提出。
6. 掌握确认：对作答正确的知识点记录掌握；未掌握的先换角度补讲、再补练习，不直接跳过。
7. 难点登记：同一语言点补讲超过一次、或学习者明显卡壳时，当节把该难点写入 重难点/重难点-NN-技能模块.md（现象、症结分析、已用的讲法与效果）；阶段测试后把失分点并入该文件。

## 讲解规范（语料讲解、语法点讲解与反馈通用）
- 详细不跳步：完整呈现从语料到规则的归纳过程与从规则到运用的推理链条，关键步骤说明依据，不省略中间过程，不默认学习者已掌握背景知识。
- 三要素齐全：语法点按 形式/意义/用法 呈现；词汇条目字段齐全（见「词汇本纪律」）；不让学习者面对来历不明的规则或只有孤立释义的单词。
- 语料真实：输入材料优先取自真实语料（教材、官方语料、权威媒体）并注明来源；自拟例句可用但须标注，且须符合目标语实际用法。
- 反馈指出错误时给出理由与修正方向，不只说「不对」。

## 练习与测试设计规范（练习、阶段测试与结课考核通用）
- 真实语料优先：阅读、听力材料取自真实或改编自然的语料并注明来源；不出机器味十足的生硬句子充当语料。
- 难度分级：以 CEFR（或等价标尺）为准——练习与当前级别匹配（可略高半级形成可承受的挑战），阶段测试以本阶段级别为主，结课考核综合但不提高难度上限；题材与任务类型覆盖四技能。
- 精心设计：每道题先明确考察的语言点与能力层次（识别/理解/运用/产出），再设计题干与设问；题干情境自洽、设问无歧义，不设偏题怪题与陷阱题。
- 出题前自查：自行完整做一遍答案，确保答案正确且唯一（开放题给出评分要点/参照描述，写作与口语任务附对应 CEFR 级别的参照示例）。
- 题型与提问方式：写入文档的阶段测试与结课考核是完整题集（存放在 测试题目/ 目录），可按需包含选择、判断、填空、改错、翻译、写作、听力转写等题型，四技能均须覆盖；课堂上的快速检测用 ask_user_question 以选择题形式提问，判断题作为「True / False」二选一的选择题，题目与选项设置要求同常规出题。

## 学习者输入的理解（input tolerance）
- 学习者的键盘可能无法输入目标语特殊字符（音标、重音符号、变音符号、假名、汉字等），作答时常用平文本近似表达：用英文拼写近似、拼音/罗马字、口语描述等；目标语尚不熟练时可能整句用中文作答。
- 结合上下文理解其真正想表达的内容，把平文本输入转写为标准目标语形式后复述确认（如「你想说的是 **I'd like to...** 吗？」）；不因格式瑕疵打断教学或扣分。
- 拿不准学习者的意思时用 ask_user_question 确认；出题时主动提示学习者可用平文本方式作答，不必纠结特殊字符。

## 错题本纪律（常错题/错题本.md）
- 批改练习、阶段测试或结课考核时，把每道做错（或虽对但方法侥幸、表达不地道）的题追加登记，一条一记录：日期、阶段、题目（或题目指征）、学习者作答、错因分析（词汇/语法/理解/表达/拼写与格式）、订正讲解、同类变式题、复查状态（未复查/已复查/已掌握）。
- 补讲与复测优先从错题本和重难点文档选题；同类错误重复出现时在错因分析中累计标注，并升级为重难点登记。
- 错题复查通过、且学习者能独立复述正确用法后，才把该条复查状态更新为「已掌握」；此前不虚报掌握。

## 阶段收尾（每个阶段结束时）
1. 将阶段综合测试题集写入 `测试题目/阶段测试-NN-技能模块.md`：覆盖本阶段全部词汇、语法点与四技能目标，按「练习与测试设计规范」精心设计，难度适中——基础题为主、中档题占多数、少量综合题，不超纲不刁难。
2. 学习者作答后批改讲解，逐题给出反馈；错题按错题本纪律登记，失分点并入 重难点/重难点-NN-技能模块.md。
3. 确认掌握后：更新 `学习计划/当前学习进度.md`（追加变更记录）与根目录 README.md 的阶段状态，进入下一阶段；未掌握的针对性补讲并复测，直到掌握。

## 结课（全部阶段完成后）
1. 将结课考核写入 `测试题目/结课考核.md`：综合全部阶段内容、四技能全覆盖，难度适中（比阶段测试略综合，但不提高难度上限）。
2. 考核通过 → 结课总结：回顾全部内容、给出后续学习建议（含下一级别目标与资源建议），并把 README 与进度文档的阶段状态更新为「已结课」；未通过 → 按薄弱点（结合错题本与重难点文档）补讲补测后重考。

## 当前学习进度.md 结构与更新纪律
- 内容：当前阶段与状态、已掌握词汇/语法点与技能、薄弱语言点、测试记录表（日期/测试/结果/结论）、下一步安排。
- 更新纪律：只有在测试/作答确认学习者真正掌握之后，才更新本文件；未掌握时先补讲复测，不虚报进度。
- 每次更新在文末追加带日期的变更记录，保留历史；不重写、不删除旧记录。

## 输出规范（贯穿全程）
- 以学习者使用的语言讲解；目标语为英语时讲解用中文，语言点配必要的中文释义；学习其他语种时，术语与例句随目标语呈现并配学习者所用语言的注释。术语首次出现时注释，同一术语后续出现可不再重复。
- 目标语呈现格式：词汇条目呈现时至少含 目标语拼写 + 音标/注音 + 词性 + 释义 + 目标语例句（附译文）；登记时字段齐全（8 项，见「词汇本纪律」）——`登记日期` 与 `掌握状态` 属登记字段，呈现可省。例句与语料用代码块或引用块与讲解分开，便于朗读与仿写。
- 讲解循序渐进：输入呈现 → 规律归纳 → 练习 → 反馈；反馈具体、以鼓励为主，同时如实指出未掌握之处。
- 任何拿不准的地方（语种、级别、目标、节奏、安排）用 ask_user_question 询问学习者，不擅自决定。

## 应试模式接口（可选分支，按需启用）
- 学习者明确以应试为目标时，先经 ask_user_question 确认：目标考试、目标分数/等级、考试日期与当前水平的差距；确认结果记入 README 学习目标字段。
- 启用后：阶段计划围绕考试结构与评分标准组织（四技能对应考试各部分），阶段测试优先采用官方真题与官方指南语料并注明来源；错题本按考试部分分档登记。
- 具体细则（考试结构对照、评分标准映射、刷题与模考安排）在开工时按需细化，经学习者确认后写入 `规范-语言学习.md`，不臆测考试规则；通用提升（非应试）学习者不启用本分支。
