# 视角与叙事距离（pov-craft）

## 何时使用
- 新作品确定叙事人称与视角时。
- 每次写作前核对本章视角纪律。
- 用户抱怨"视角乱""代入感差"时。

## 视点配置系统（POV Configuration）

本作品在 `规范-创作.md` 中声明**全局默认视点模式**；单章可通过章头显式交接视点。绝不使用"绝对禁止他人内心/绝对单一视角"之类一刀切死规则——视点纪律是**动态模式配置**，事实严密与艺术自由并重。

### 模式 1：第一人称单视角（First-Person Single POV）
- 定位：第一人称单主角叙事、强代入、悬疑探秘、纯主观体验。
- 规则：全书（或全卷）严格绑定单一视点角色；他人内心完全不可见；视线死角受人体物理法则约束（背后动静只能靠听觉、触感或他人事后转述感知）。
- 章头无需逐章标注视点（默认继承全局主视点）。

### 模式 2：第三人称限知·章级轮换（Switching POV）
- 定位：双主角对等叙事、双向暗恋心声交锋、群像多线推进。
- 规则：允许按章切换主导视点；视点归属于谁，谁即获得内心独白与感官特权。
- 每次交接必须在章头显式声明 `【视点：角色】`。

### 模式 3：第三人称全知（Omniscient）
- 定位：史诗群像、宏观多线、多势力智斗、宏观灾难与幕间发生之事。
- 规则：允许客观叙述、全知视角与主线之外的幕间发生之事，可交代任一角色的行动与场面。
- 全知章用 `【视点：全知】` 声明：无单一视点角色，采用全知叙述白描。

### 动态特权与限制转移（视点一旦交接，立即生效）
1. **特权转移**：声明 `【视点：夏天风】` 后，夏天风的内心独白立即合法且优先；叙述中的"他/她"自动指称视点角色（模式 2），并自动限定在夏天风的所见所闻所思；心理活动、嗅觉、触觉等全部感官以夏天风的身心感受为准。
2. **限制转移**：此时原视点角色退行为外部观察对象，**严禁书写其内心**（其心理活动不得再以内心独白形式出现）；其心情只能通过外在动作（挠头、移开视线、喉结微动）被当前视点角色观察。
3. **多心声禁令（No Simultaneous Mind-reading）**：**绝对禁止在同一个段落或场景中同时出现两个角色的无声内心独白**，杜绝"神游视角漂移"。一个段落或场景内，内心特权只有一份。

### 章头视点声明语法
- 基础章头：`# 第 N 章 <章节名>`（如 `# 第 2 章 旧书店后廊`）。
- 模式 2 交接视点：`# 第 2 章 旧书店后廊 【视点：夏天风】`（显式交接：本章主导视点移交给夏天风）。
- 模式 3 全知章：`# 第 3 章 老街尽头公用电话亭 【视点：全知】`。
- 未显式声明时，默认继承全局默认主视点（由 规范-创作.md 声明）。

## 视角类型
- 第一人称（我）：代入感强、信息天然受限；容易写成自白腔；适合悬疑、成长与强个性叙述者。
- 第三人称限知（他/她，跟随一人）：兼具代入与调度自由；纪律要求高，视角一漂移就穿帮；长篇主流选择。
- 第三人称全知：上帝视角，便于多线铺陈与史诗感；代入感弱，容易信息倾倒；适合群像与历史题材。
- 第二人称（你）：实验性强，代入与间离并存；风险高；非特殊构思不建议。

选择原则：视角与信息差设计绑定——视角决定"读者知道什么、何时知道"（见 writing-craft 悬念与信息差）；选定后由 `规范-创作.md` 声明全局默认视点模式（见「视点配置系统」）。

## POV 纪律
- 一章（或一个场景）内跟随一个视点角色：只写其看到、听到、想到、感到的；不进入他人内心。
- 视角内不写"视角外事实"：如视点角色不知道的阴谋细节，除非经由其推理、观察或对话获得。
- 情绪与判断只能从当前视角出发；他人情绪靠外部表现（表情、动作、语气）呈现。

## 多视角轮换
- 轮换点放在章节边界（模式 2 为章级轮换，章头声明 `【视点：角色】`，见「视点配置系统」），用标题、空行或其他稳定标志区分；一章内不停跳。
- 同一事件不重复覆盖：同一时间线由一条视角线承担主视角，其余视角用结果、侧面或事后补述带过。
- 每个视点角色必须提供不可替代的信息或体验：换视角要"换到新东西"，否则合并。
- 关键事件的读者认知受视角顺序控制：先给哪个视角 = 先给哪种情绪/悬念。

## 叙事距离（镜头远近）
- 远景：概括事件、时间跳跃、氛围铺陈——用在转场与缓冲。
- 中景：正常叙事推进——情节主体。
- 近景/特写：感官细节、动作微表情、内心感受——用在高潮与情感点。
- 距离切换要有节奏：全程特写会累，全程远景会飘；按"情节强度"匹配距离。

## 内心独白与自由间接引语
- 限知视角下，角色内心可以用自由间接引语与叙述融合（"他攥紧车票。今天非走不可了。"），比"他想：……"更顺滑，但要与正文叙述保持可辨识的界线（见 style.md）。
- 内心独白口径（坦率/自我欺骗/碎碎念）要稳定，登记进 character-voices.md，与对白形成"第二声部"。

## 检查清单
- [ ] 本章视点角色明确，章头声明到位（模式 2），全文无漂移
- [ ] 无视角外信息泄漏
- [ ] 无多心声违规（一个段落或场景内内心特权只有一份）
- [ ] 多视角切换有标志、有增量信息
- [ ] 叙事距离与情节强度匹配
- [ ] 独白口径与角色声音一致
