# 党政机关公文规范（spec-govt-gbt9704，定稿版 2026-09-10）

> 用途：开工规范检查选默认集「党政机关公文」时，本 skill 是 `规范-公文.md` 的内容母本（四节骨架、写法通则与执行要求的纳入方式见 spec-common；落盘时记录来源为「本预设默认集·党政机关公文（2026-09-10 定稿）」）；党政公文起草与校对阶段随时对照执行。

## ① 来源记录
- 《党政机关公文处理工作条例》（中共中央办公厅、国务院办公厅联合印发，2012-04-16 印发、2012-07-01 施行）——文种与行文规则的唯一权威依据；
- GB/T 9704-2012《党政机关公文格式》（2012-06-29 发布、2012-07-01 实施，代替 GB/T 9704-1999）——版式与要素编排规则；
  - 核验要点：**发布日 2012-06-29** 与《条例》印发日 **2012-04-16** 是两个不同日期，勿混用；标准文本可在全国标准信息公共服务平台（std.samr.gov.cn）按标准号查询。
- 定稿时间：2026-09-10（据检索摘要提炼，用户批注修订后复请确认）。

## ② 结构与目录约定
- **15 种法定文种**及适用范围：见 doc-types 的「党政机关 15 种法定文种（《党政机关公文处理工作条例》）」表；本规范不重复列举，文种判定以该表为准。
- **公文格式 18 要素**：份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人、标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注、附件、抄送机关、印发机关和印发日期、页码。
- 版面分区：**版头**（份号/密级/紧急程度/发文机关标志/发文字号/签发人）→ **主体**（标题/主送/正文/附件说明/署名/成文日期/印章/附注）→ **版记**（抄送/印发机关和日期）。
- 项目目录按「文种档案制」：01-定稿 / 02-草稿（`<文种>-<主题>-v<n>.md`）/ 03-依据材料 / 04-校对记录。

## ③ 产出格式规范
- 标题三要素：**发文机关名称 + 事由 + 文种**（如《×× 关于××的通知》）；文种不得省略或自造。
- 发文字号：机关代字 + 年份 + 顺序号，年份用六角括号〔〕标全称，顺序号不加「第」字、不编虚位、后加「号」（如 X 发〔2012〕5 号）。
- 上行文须标注签发人（居右空一字，与发文字号同行）；份号用 6 位 3 号阿拉伯数字顶格；密级 3 号黑体顶格；份号/密级/紧急程度自上而下分行排列。
- 发文机关标志：全称或规范化简称（可加「文件」二字），红色小标宋体居中，上边缘至版心上边缘 35mm。
- 正文结构惯例：缘由（依据/目的）→ 事项（分条列项）→ 结语（文种惯用语，如「特此通知」「妥否，请批示」「此复」）。
- 行文规则：请示**一文一事**；上行文原则上主送一个上级机关；一般不得越级行文；联合行文用主办机关发文字号。
- **人民为中心——本心与内核，而非文中口号**（定稿增补 2026-09-10）：这是起草者的立场与自查纪律，不要求也不应作为一句口号写进公文。落法是：起草前先弄清「这件事落到哪类群众/基层单位身上意味着什么、哪里可能落空」，以此校准事项的针对性与可执行性；重要决策事项须体现对群众切身利益及各方面影响的考量。
- **内容落点要求（从实际出发）**（定稿增补 2026-09-10）：事项部分落到「做什么、谁来做、何时完成」，可核验；「加强」「完善」「进一步」类表述不得单独充当措施。
- **多方面考虑（影响面检视）**（定稿增补 2026-09-10）：涉及利益调整与执行的公文，起草前对不同群体、上下游环节、执行端可行性逐一过一遍；未考虑到的方面如实标注「待确认」，不得装作已周全。

## ④ 红线与禁忌
- 禁止文种混用错用（最典型：在报告等非请示性公文中夹带请示事项；「请示」与「报告」混为一谈）。
- 禁止自造文种（如「关于××的申请」不是法定文种，应按受文对象改用请示或函）。
- 禁止越权表述：非授权的办公厅（室）不得向下级党委、政府发指令性公文；涉及多部门职权未协商一致不得行文。
- 禁止使用第一人称口语化套语、文学化修辞与情绪化措辞；称谓用机关全称/规范化简称，不得用「我局领导」「咱们」。
- 数字、计量单位、标点按国家标准执行（GB/T 15834 标点符号用法、GB/T 15835 出版物上数字用法）；成文日期署签发日期，不得提前或虚填。
- 禁止以口号与表态句代替实质内容（定稿增补 2026-09-10）：「高度重视」「深入贯彻」类语句只能作惯例性衔接，工作部署须落到具体动作、责任主体与时限；表述平实为要，不追求辞藻与排比气势。

## 执行要求（写入 规范-公文.md 时随结构节一并纳入）
- 起草前依据材料收集未完成、关键政策口径未经用户确认的，不得进入成稿；正文每个数字与引用须能回溯 03-依据材料/ 的对应条目。
- 逐项校对按 doc-review 执行，重点核查：要素齐全性与版面分区落位、文种与行文方向一致、口径与依据可溯源、数字与计量符合 GB/T 15835/15834、无口号代实质与内容落点缺失。
