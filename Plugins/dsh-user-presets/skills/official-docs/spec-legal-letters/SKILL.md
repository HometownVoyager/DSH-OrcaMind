# 法律函件规范（spec-legal-letters，定稿版 2026-09-10）

> 用途：开工规范检查选默认集「法律函件」时，本 skill 是 `规范-公文.md` 的内容母本（四节骨架、写法通则与执行要求的纳入方式见 spec-common；落盘时记录来源为「本预设默认集·法律函件（2026-09-10 定稿）」）；法律函件起草与校对阶段随时对照执行。

## ① 来源记录
- 律师函/催告函等函件类法律文书的行业通行体例（律师执业实务与法律文书写作通例整理）；
- 定稿时间：2026-09-10（据检索摘要提炼，用户直接定稿）。

## ② 结构与目录约定
- **首部**：标题（「律师函」「催告函」「告知函」「复函」+ 编号）、致送对象（自然人/法人全称，法人用注册全称）。
- **正文五要素**：①委托关系声明（受××委托，××律师事务所指派××律师就××事宜致函）→ ②事实陈述（时间线清晰，逐项与证据对应）→ ③法律依据（引用具体法律条文，条文序号精确）→ ④要求事项（明确、可执行、可核查）→ ⑤期限与后果（限定答复/履行期限；逾期将采取的法律措施）。
- **尾部**：律师事务所全称 + 经办律师姓名 + 执业证号 + 联系方式 + 出函日期。
- 项目目录沿用「文种档案制」，03-依据材料/ 收录证据清单与法条原文摘录。

## ③ 产出格式规范
- 当事人首次出现用全称并括注简称（后文统一用简称）；日期用公历全写（如 2026 年 9 月 10 日）；金额同时写大写与小写。
- 法条引用格式：《法律名称》第 X 条第 X 款；引用须以现行有效版本为准，并在依据材料中留存原文。
- 措辞克制、语义封闭：要求事项用「限于…日内」「应当」，不使用弹性措辞；一份函件只处理一项争议事由。

## ④ 红线与禁忌
- **本套产出为起草稿性质**：agent 产出的任何法律函件须声明「非正式法律意见，使用前须经执业律师审核」，不得替代律师出具正式文书。
- 禁止威胁、恐吓、侮辱性措辞与人格贬损；禁止虚构事实、夸大事实或无证据指控。
- 禁止在函件中泄露委托人无关个人信息与他人隐私；证据表述与 03-依据材料/ 中证据一一对应，不得超出证据范围。
- 禁止引用已废止/已修改法条；对法律适用有争议的点，须标注「待律师确认」而非替用户下结论。

## 执行要求（写入 规范-公文.md 时随结构节一并纳入）
- 起草前证据清单与法条原文摘录必须先落 03-依据材料/；正文事实陈述逐项与证据对应，超出证据范围的事实不写。
- 逐项校对按 doc-review 执行，重点核查：五要素齐全、法条引用与现行有效版本一致、当事人简称使用统一、金额大写小写一致、期限与后果表述语义封闭、无证据外指控。
- 每份定稿交付时保留「起草稿性质」声明，提醒用户经执业律师审核后使用。
