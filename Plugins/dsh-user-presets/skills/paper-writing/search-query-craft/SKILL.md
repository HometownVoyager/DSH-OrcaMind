# 搜索词联想构建（search-query-craft）

> **本预设场景（paper-writing）**：论文写作。重点服务文献检索、研究缺口核实、数据与政策原文溯源、反面证据刻意检索。
> **纪律与归档**：按 persona「文献与检索纪律」执行；命中文献登记 01-文献/ 文献库并注明获取状态（据全文 / 据检索摘要）。

## 何时使用
- 围绕议题/问题启动 `web_search` 之前：把模糊的信息需求拆成一组可执行的检索词。
- 单角度检索结果单薄、视野偏窄或只看到一种立场时：换维度重建检索词。

## 核心方法：五个联想维度
从议题或问题（写成一句话）出发，沿以下维度各生成一组检索词，每组 2-5 个：

1. **事实经过**：发生了什么、时间线、关键节点。检索词含事件主体 + 时间 + 关键动作（如「<事件> 时间线」「<主体> <年月> 通报」）；优先官方通报、新闻标题句式。
2. **机制链条**：事情如何发生、通过什么环节影响谁。检索词含机制词（成因/传导/影响/链条/路径）+ 领域词（如「<现象> 成因 传导机制」「<政策> 执行 落地」）；找分析类与研究类来源。
3. **各方立场**：谁受益、谁受损、谁执行、谁监管、谁反对。检索词按主体逐一展开（如「<群体> 反应」「<部门> 表态」「<专家> 观点」）；刻意检索与初步判断相反的关键词。
4. **数据与政策原文**：统计口径、现行规定、历史沿革。检索词含数据/公报/文件号（如「<主题> 统计公报 <年份>」「<文件名> 全文」「<政策> 文号」）；优先一级信源。
5. **已有评论与反驳**：媒体评论、学界批评、公众讨论与反驳观点。检索词含评论词（评论/批评/争议/反驳/质疑）+ 议题词；目的包括找反方最强观点（供反驳预案）。

**延伸维度：学术文献检索**（议题存在学术文献时叠加）：在五个维度之上补一组文献检索词——主题词 + 方法词 + 同义学术表述（中英双语）、高被引综述的参考文献追溯（顺藤摸瓜）、检索式布尔组合（AND/OR/NOT）。

## 构建纪律
- **多角度优先**：每轮检索至少覆盖三个维度；只搜事实经过不搜立场与反驳，是最常见的检索失衡。
- **同义改写**：同一概念准备 2-3 种表述（口语/术语/官方语三种语域），如「<俗称> / <行业术语> / <正式文件称谓>」。
- **限定与扩展交替**：先用窄检索词锁定核心事实，再用宽检索词扫盲区（去掉限定词、换上位概念）；发现新的关键主体或概念，回到维度循环补充检索。
- **反向检索**：刻意构建「证伪自己初步判断」的检索词（反方关键词 + 反例关键词）；检索不到反驳不等于反驳不存在，标注「未检索到相反观点」。
- **语言分轨**：中文议题可用英文检索词补充国际视角与学术来源；引用外文信源注明原文出处。
- **记录**：检索词、检索轮次与结果去向（命中哪条信源或结论）随手记入检索记录，避免重复检索、便于回溯。

## 检索词组模板
```markdown
# 检索词组：<议题/问题一句话>
- 事实经过：「<主体><时间><动作>」「<事件> 时间线」「<事件> 通报」
- 机制链条：「<现象> 成因」「<政策> 执行效果」「<影响> 传导」
- 各方立场：「<主体A> 表态」「<群体B> 影响」「<专家/机构C> 评估」
- 数据与政策：「<主题> 统计 <年份>」「<文件名> 全文」「<政策> 文号」
- 评论与反驳：「<议题> 评论」「<议题> 争议」「<论点> 反驳」
- 反向证伪：「<初步判断的反面> + 领域词」
- 学术文献（议题有文献可查时）：「<主题词> <方法词> study」「<主题> review」「<英文同义词> OR <英文同义词>」
```

## 注意事项
- 检索是考据的手段不是结果：检索词覆盖面再广，所得结论仍需交叉验证、注明来源、区分事实与建议后才可用（本预设的纪律条款与归档去向见文首「本预设场景」）。
- 单轮检索题量控制：先广后深，命中关键信源后优先用 `web_fetch` 取原文核读，不在搜索结果摘要上做结论。
- 检索不到预期信息时如实报告（检索了什么词、来自哪些维度），不虚构「检索表明……」。
