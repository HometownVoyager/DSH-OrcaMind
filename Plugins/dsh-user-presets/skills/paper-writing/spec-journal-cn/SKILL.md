# 中文期刊论文规范（spec-journal-cn，定稿版 2026-09-10）

> 用途：开工规范检查选默认集「中文期刊论文」时，本 skill 是 `规范-论文.md` 的内容母本（四节骨架、写法通则与执行要求的纳入方式见 spec-common；落盘时记录来源为「本预设默认集·中文期刊论文（2026-09-10 定稿）」）；期刊论文起草与格式化校对阶段随时对照执行。**目标期刊的最新投稿须知为最高优先级**，本套为无指定期刊时的通用缺省。

## ① 来源记录
- 中文核心期刊通用投稿体例（多刊投稿须知综合）；
- GB/T 7713.2-2022《学术论文编写规则》（2023-07-01 实施）——学术论文编写的现行国家标准；
  - 核验要点：**GB/T 7713.1 是《学位论文编写规则》，不适用于学术论文**；学术论文对应的是 GB/T 7713.2-2022，两者勿混用（本套 2026-09-10 版曾误写为 7713.1，2026-09-12 订正）。
- GB/T 7714-2015《信息与文献 参考文献著录规则》——著录规则；
- 定稿时间：2026-09-10（据检索摘要提炼，用户确认定稿）。

## ② 结构与目录约定
- 题录区：题名（含英文题名）→ 作者与单位（含通讯作者标注）→ 摘要（含英文摘要）→ 关键词（3–8 个，含英文关键词）→ 中图分类号（可选：文献标志码、DOI）。
- 正文：引言（研究背景与问题，不与摘要重复）→ 研究设计/方法 → 结果与分析 → 讨论 → 结论；基金资助与作者简介以首页脚注标注。
- 参考文献：按 GB/T 7714 著录，正文标注体系以目标期刊要求为准（国内刊以顺序编码制为主流）。
- 项目目录沿用「研究档案制」；投稿版式以**目标期刊最新投稿须知为最高优先级**，本套为无指定期刊时的通用缺省。

## ③ 产出格式规范
- 摘要为独立短文（一般 200–300 字），说明目的、方法、结果、结论；不出现「本文」「笔者」以外的第一人称，不写背景铺垫长句。
- 图表随文出现、先见文后见图表，编号连续；数据表注明统计口径与显著性标注约定。
- 参考文献著录以 GB/T 7714-2015 为准：专著、期刊析出、学位论文、电子资源等文献类型标识（[M]/[J]/[D]/[EB/OL] 等）与项目齐全，顺序编码制按正文出现顺序连续编号。

### 图表可读性规则
1. **自明性优先**：本套的「图表随文出现、先见文后见图表」之外，表题须置于表上方、图题置于图下方，题注交代数据来源、统计口径与显著性标注约定，读者不读正文即可读懂该表在说什么。
2. **方向与单位**：指标列标出方向（如「相关系数 ↑」）与单位，多指标并列时表头写清各自的量纲，不留需读者推断的列。
3. **精度与对齐**：同一指标列内小数位数一致，数值列按小数点对齐、文字列左对齐；显著性标记（*/**/***）在表注中给出对应水平。
4. **一表一讯息，少用线条**：一张表只承担一个结论；采用三线表，不用竖线，横线只用于分隔数据组而非每一行；分组或分场景的结果用跨列表头或分组线区分。
5. **正文引述**：正文必须引述每个图表的关键信息并说明它支撑哪个论断，不得只写「见表 2」；表题图题控制在交代条件与符号的范围内，不写讨论。图表张数与版式以目标期刊投稿须知为准。

### 双盲送审红线（采用双向匿名评审的期刊）
- 投稿版须删除作者姓名、单位、通讯地址、邮箱、致谢、基金资助与作者简介等可直接识别身份的内容；投稿须知另有规定的，以其规定为准。
- 正文自引改写为第三人称表述；确须引用本人已发表成果时，按该刊匿名要求处理（如以「文献 [x]」形式引用并在说明中记录），避免经由著录条目暴露身份。
- 文档属性（作者、单位、最后保存者）与文件名同样会泄露身份，交付送审版前清除。
- 图表中若含单位名称、实验室标识、设备铭牌或可定位的实地照片，须遮蔽或以示意图替代。
- 非匿名评审的期刊不适用本节；不得因本套缺省而给投稿版强加匿名要求。

## ④ 红线与禁忌
- 一稿多投、重复发表为绝对红线；投稿前自查查重。
- 禁止摘要与引言互相复制；禁止结论夸大到数据不支持的力度。
- 禁止引用与自己论点无关的文献凑数、强制自引；每条引用须真实可核验（与文献库获取状态联动）。
- 期刊特有格式（字数上限、图表张数、参考文献条数）以投稿须知为准，不得以本套缺省覆盖目标期刊的明确要求。
- 图表违反「图表可读性规则」（缺单位/缺方向标注/精度不一致/一表多讯息/正文只写「见表」）→ 格式化核查按未通过记，修复后复核。
- 目标期刊采用双向匿名评审而投稿版残留身份信息（作者、单位、致谢、基金、文档属性）→ 不得投稿。

## 执行要求（写入 规范-论文.md 时随结构节一并纳入）
- 开工时先向用户确认目标期刊：有指定期刊的，web_search 其最新投稿须知并作为最高优先级记录进 规范-论文.md；无指定时按本套缺省执行并声明「缺省版」。
- 起草前文献综述未完成、引用未入库的不得成稿；正文每个数字与引用能回溯 01-文献/ 与 04-图表数据/ 的对应条目。
- 格式化与引用定稿阶段按 paper-revision 的核查表逐项核对：题录区要素齐全、摘要规格、图表随文编号与图表可读性规则、著录格式与类型标识、无列而不引/引而不列。
- 目标期刊采用双向匿名评审的，交付前按「双盲送审红线」逐项清除身份信息，并在 05-修改记录/ 登记检查结果。
