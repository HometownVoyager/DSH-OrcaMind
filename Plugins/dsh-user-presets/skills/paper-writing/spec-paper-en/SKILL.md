# 英文论文规范（spec-paper-en，定稿版 2026-09-10）

> 用途：开工规范检查选默认集「英文论文」时，本 skill 是 `规范-论文.md` 的内容母本（四节骨架、写法通则与执行要求的纳入方式见 spec-common；落盘时记录来源为「本预设默认集·英文论文（2026-09-10 定稿）」）；英文论文起草与格式化校对阶段随时对照执行。目标期刊 author guidelines 为最高优先级。

## ① 来源记录
- IMRaD 结构（Introduction / Methods / Results / Discussion，国际学术期刊主流报告结构）；
- APA 引用体系（第 7 版，作者-日期制，社会科学通用）；IEEE 引用体系（顺序编码制，工程/计算机/电子领域通用）；
- 定稿时间：2026-09-10（据检索摘要提炼，用户确认定稿）。

## ② 结构与目录约定
- Title → Authors & Affiliations → Abstract（150–250 词左右，视期刊）→ Keywords → **I**ntroduction（背景 → 研究缺口 → 研究问题/假设 → 贡献）→ **M**ethods（设计、样本、数据收集、分析工具，须足以复现）→ **R**esults（发现陈述 + 图表 + 统计量）→ **D**iscussion（解释与既有研究比较 → 意义 → 局限性 → 未来方向；可合并 Conclusion）→ References →（可选 Appendix / Supplementary Materials）。
- 项目目录沿用「研究档案制」；英文论文的分节文件与 01-文献/ 内笔记均可用中文记录，正文稿为英文。

## ③ 产出格式规范
- 引用体系二选一，全文统一：**APA 7**——文中（Author, Year），参考文献表按作者字顺排、悬挂缩进，DOI 尽量齐全；**IEEE**——文中方括号 [1]，按出现顺序编号，参考文献表按编号排，期刊用缩写刊名。默认无指定期刊时，理工科用 IEEE、社科用 APA，开工时向用户确认。
- 时态惯例：Methods 与 Results 用过去时；Introduction/Discussion 中的普遍事实用现在时；图表标题为短语式（不完整句）。
- 数字与统计：统计量斜体（p, t, F），p 值报告到三位小数；缩写首次出现给全称，此后一律用缩写。

### 图表可读性规则
1. **方向与单位**：指标列在表头标出方向与单位（如 `Accuracy (%) ↑`、`RMSE ↓`），读者不必推断数值的优劣方向与量纲。
2. **精度一致**：同一指标列内小数位数保持一致；文字列左对齐，数值列对齐方式统一（需要按小数点对齐时可用 siunitx 一类的对齐方案，风格从简）。
3. **少线分组**：主表采用三线表（顶线、表头线、底线），不用竖线，不用连续横线分割每一行；多数据集或多设定分组用跨列表头加分隔线表达，不用竖线或嵌套列。
4. **一表一讯息**：一张表只承担一个结论，不把互不相关的结果并进同一张表；行代表不同设定或不同属性时，在行名或属性列中明确写出。
5. **题注与正文**：图表标题用短语式并交代设定、协议与符号约定，不在标题里展开讨论；正文必须引述每个图表的关键信息并说明它支撑哪个论断，不得只写「see Table 3」。单栏图表在双栏排版中的位置属于排版层问题，以目标模板为准。

### 会议投稿条件分支（仅在用户明确说明是会议投稿时启用）
- 用户确认按某会议投稿时，向用户取得该会议的 author guidelines 与模板，并将**页数上限、模板版式、字体与图表要求、补充材料规则、匿名评审要求**作为最高优先级执行：核查篇幅是否超限、按模板排版、送审版去除作者与单位信息及致谢。
- 交付 PDF 前核查输出是否完整可读、是否有未解析的交叉引用或引用标记（编译日志中不应残留 undefined reference / undefined citation 一类警告），并向用户报告页数与仍待处理的事项。
- 与字数上限、camera-ready 版本的字体嵌入、文件体积上限等相关的约束，**只在用户明确说明处于该阶段时适用**；用户未提及投稿类型或阶段时，不得把会议投稿机制当作默认规则加在稿子上，也不得主动施加页数或版式限制。
- 用户投的是期刊或学位论文流程时，本节不适用，按对应 spec 与目标单位要求执行。

### 英文骨架句与 LaTeX 使用边界
- 下列骨架句只用于英文稿，供起草时确定句子职能，不构成可直接照抄的成文句子；**不得把英文骨架直译进中文正文**，中文稿按中文行文重组（见 academic-drafting 的语体纪律）。
  - 界定研究对象：`This paper addresses [problem] by [approach].` / `We study whether [relationship] holds under [conditions].`
  - 指出既有不足：`Prior work on [topic] has focused on [aspect]; however, [limitation] remains because [reason].`
  - 给出贡献与区分：`Our contribution is [contribution]. In contrast to prior work, we [difference], which allows [capability].`
  - 交代设计与动因：`We [design choice] because [problem it addresses].` / `Given [input/condition], we first [step], then [step].`
  - 交代优势与证据：`This design yields [advantage], as shown by [result/figure/table].`
  - 结果与边界：`[Finding] was observed in [setting]; this pattern did not hold for [boundary case].`
- 时态与数字惯例按本节第 ③ 部分的时态惯例与数字统计条款执行；术语首次出现给全称与缩写，此后全文用同一术语，不换同义词。
- 数学与公式：公式只在确有必要时编号，变量与符号在首次出现处给出含义并与正文用词一致；具体排版（编号位置、转行规则）在定稿排版阶段按目标模板落实，起草阶段不做命令层面的处理。
- 若项目以 LaTeX 工程交付，编辑时保持引用标记、交叉引用与标签不被破坏；编译不通过时排查根因，不通过删内容、注释掉引用或移除宏包来绕过报错。若正文稿以 Markdown 或 Word 形式交付，则不在其中引入 LaTeX 命令。

## ④ 红线与禁忌
- 学术不端零容忍：不伪造/篡改数据，不抄袭与不当改写（paraphrase 仍须引用），不捏造或操纵文献。
- Results 只报告发现，不得夹带解释（解释归 Discussion）；Discussion 不得重复罗列 Results 数字。
- 禁止中式英语直译腔与营销化形容词（novel、significant 慎用，significant 专指统计显著）；禁止在正文与图表中重复展示同一数据。
- 期刊具体模板（版式、字数、结构微调）以目标期刊 author guidelines 为最高优先级；会议投稿另见「会议投稿条件分支」，其页数与版式约束只在用户明确该阶段时启用。
- 图表违反「图表可读性规则」（缺单位/缺方向标注/精度不一致/一表多讯息/正文只写 see Table）→ 格式化核查按未通过记，修复后复核。

## 执行要求（写入 规范-论文.md 时随结构节一并纳入）
- 开工时确定引用体系（IEEE/APA）与目标期刊（如有）并记入 规范-论文.md；无指定期刊时按理工 IEEE / 社科 APA 缺省并向用户确认。用户明确是会议投稿时，同时记录目标会议与阶段（初投/返修/最终版），据此决定是否启用会议投稿条件分支。
- 正文稿为英文、工作语言仍为中文：分节文件可先出中文逻辑稿再转英文终稿，或直接英文起草，方式经用户确认；英文骨架句用于英文终稿的句子职能定位，不直译进中文正文。
- 每个非原创论断随文标注（APA 作者-年份 / IEEE 编号），与 01-文献/ 文献库条目一一对应；未读全文的文献不得作为论证依据（预设文献检索深度边界）。
- 格式化与引用定稿阶段按 paper-revision 的核查表逐项核对：IMRaD 职能边界、引用体系全文统一、时态惯例、统计量与 p 值格式、图表标题短语式与图表可读性规则。
