# 中文学位论文规范（spec-thesis-cn，定稿版 2026-09-10）

> 用途：开工规范检查选默认集「中文学位论文」时，本 skill 是 `规范-论文.md` 的内容母本（四节骨架、写法通则与执行要求的纳入方式见 spec-common；落盘时记录来源为「本预设默认集·中文学位论文（2026-09-10 定稿）」）；学位论文起草与格式化校对阶段随时对照执行。院校/学位办有明确模板要求时以其为最高优先级。

## ① 来源记录
- GB/T 7713.1-2006《学位论文编写规则》（代替 GB/T 7713-1987 中学位论文部分；采用 ISO 7144:1986《文献 论文和相关文献的编写》，**非等效采用 NEQ**）——结构与编写规则；
  - 核验要点：本标准的采标对象是 **ISO 7144**，不是 ISO 690；ISO 690 对应的是**著录规则**语系（即下一条 GB/T 7714），勿把两者混写。
- GB/T 7714-2015《信息与文献 参考文献著录规则》——引文标注与参考文献表；
- 定稿时间：2026-09-10（据检索摘要提炼，用户确认定稿）。

## ② 结构与目录约定
- **五部分结构**（GB/T 7713.1-2006 第 5 章）：前置部分（封面 → 封二 → 题名页 → 序或前言 → 摘要 → 关键词 → 目次页 → 图和附表清单 → 符号/缩略词注释表）→ 主体部分（引言/绪论 → 各章 → 结论或讨论）→ 参考文献表 → 附录 → 结尾部分（必要时：文献题录 → 索引 → 后记与致谢 → 导师简介 → 作者简介）→ 学位论文数据集。**致谢属结尾部分，不在前置部分**；院校模板要求在摘要前加原创性声明、或另设勘误页的，以院校模板为准。
- 题名页要素：中图分类号、学校代码、UDC、密级、学位授予单位、题名与副题名（中英对照）、责任者、申请学位、学科专业、研究方向、论文提交日期、培养单位。
- 项目目录按「研究档案制」（paper-project-bootstrap）：00-选题/ 01-文献/（文献库 + 笔记/）02-提纲/ 03-正文/（分节文件）04-图表数据/ 05-修改记录/。

## ③ 产出格式规范
- A4 纸打印（GB/T 7713.1-2006 4.4）；版心留边：天头与订口 ≥25mm，地脚与切口 ≥20mm（4.5）；页码从「绪论」数起（含绪论、正文、参考文献、附录、致谢）用阿拉伯数字编连续码，文摘页、目次页、插图和附表清单、符号与缩略词注释表用阿拉伯数字单独编连续码（4.7）；院校模板要求前置部分用罗马数字时以其为准。
- 题名不超过 20 字（GB/T 7713.1-2006 5.1.1.2），中英对照；中文摘要一般不宜超过 200–300 字、外文摘要不宜超过 250 个实词（5.1.5.4），摘要含目的、方法、结果、结论，重点为结果与结论，第三人称撰写，不用图表与非公知符号；关键词 3–8 个（5.1.6，尽量取自规范词表），另用显著字符另起一行排摘要下方，并附对应英文关键词。院校模板另有更宽或更严要求时以其为准。
- 章节：主体每章另起页，编号按 1 / 1.1 / 1.1.1 顶格排（GB/T 7713.1-2006 附录 B 的条文排列格式；更细的层级编号方法参见现行有效的 CY/T 35-2001《科技文献的章节编号方法》，其适用范围含科技文献、图书、连续出版物等）；图有编号（图 1，可分章编）与图题置图下方，表有编号与表题置表上方、建议三线表，续表重复表头；公式另行起缩格书写、编号右端对齐置括号内，转行在 =、+、-、×、/ 处。
- 引文标注按 GB/T 7714：顺序编码制或著者-出版年制，**全文必须统一**；参考文献表置于正文后另起页，所有被引文献均列入；未被引用但阅读过的文献集中列入附录「书目」。
- 术语、符号、代号全文统一；缩略词首次出现以译文后圆括号注原词全称；采用国家法定计量单位。

### 图表可读性规则
1. **自明性**：图题置于图下方、表题置于表上方，题注须交代数据来源、统计口径、时间范围与必要的符号说明，使读者不读正文也能看懂该图表在说什么——这是 GB/T 7713.1 自明性要求的落地写法。
2. **方向与单位**：指标列须标出方向（如「增长率（%）↑」「误差（mm）↓」）与计量单位，不得让读者猜测数值的含义与优劣方向。
3. **精度与对齐**：同一指标列内小数位数保持一致；数值列按小数点对齐，文字列左对齐；数值与文字混排时不要用空格凑对齐。
4. **一图一讯息**：一张图表只承担一个结论。需要并列展示两组互不相关的数据时拆成两图，不用一张大表塞进所有指标；分组或分场景的结果用跨列表头加分组线区分，不用竖线或嵌套列堆叠。
5. **正文引述**：正文必须引述每个图表的关键信息，写清该图表支持了哪个论断，不得只写「见表 3」。表题图题只写测定条件与符号约定，讨论与结论放进正文。

### 双盲送审红线（学位论文送审、盲审版本）
- 送审版须去除全部可识别身份的信息：作者与导师姓名、培养单位名称与校徽、致谢、个人简历、项目与基金编号中的单位标识。
- 页眉页脚、文件名、文档属性（作者、单位、最后一次保存者）都会泄露身份，交付盲审版前逐项检查并清除。
- 正文自引须改写为第三人称表述；参考文献表中本人已发表成果的著录不得暴露作者身份（涉及本人成果时，按院校盲审要求的处理方式，必要时以可核验的方式遮蔽并在说明中记录）。
- 图表中若含单位名称、实验室标识、设备铭牌或可定位的实地照片，须遮蔽或以示意图替代。
- 院校另有盲审规定的，以其规定为最高优先级；本套为无明确规定时的缺省。

## ④ 红线与禁忌
- 摘要不得写成目录式罗列或加评论与补充解释；结论不得是各章小结的简单重复。
- 图表须有「自明性」，不得与正文文字简单重复；引用文献须与文中标注一一对应，不得列而不引、引而不列。
- 图表违反「图表可读性规则」（缺单位/缺方向标注/精度不一致/一图多讯息/正文只写「见表」）→ 格式化核查按未通过记，修复后复核。
- 送审与盲审版本残留身份信息（作者、导师、单位、致谢、基金、文档属性）→ 不得交付送审版。
- 注释不宜过多，建议脚注方式，避免尾注；正文未引用的文献不得混入参考文献表。
- 学术诚信红线（预设 persona「学术诚信与辅助边界」）：不伪造、篡改数据与文献，不代写应考内容；agent 产出全部为协助性草稿，最终学术责任在作者本人。

## 执行要求（写入 规范-论文.md 时随结构节一并纳入）
- 起草前提纲未经确认、文献综述未完成的，不得进入正文成稿；正文每个数字、每条引用须能回溯 01-文献/ 与 04-图表数据/ 的对应条目。
- 格式化与引用定稿阶段按 paper-revision 的核查表逐项核对：结构五部分齐全、摘要与关键词规格、章节编号体系、图表公式格式（含图表可读性规则）、引文标注体系统一、参考文献表与文中标注一一对应。
- 院校要求送审或盲审的，交付前按「双盲送审红线」逐项清除身份信息，并在 05-修改记录/ 登记检查结果。
