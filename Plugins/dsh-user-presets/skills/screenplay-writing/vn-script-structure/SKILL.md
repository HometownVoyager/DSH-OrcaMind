# 结构与节拍（vn-script-structure）

## 何时使用
- 新剧本在 logline 确定后、写剧情大纲之前。
- 用户要求"理结构""排节拍""剧情太平/太散/共通线太水"时。

## 工作顺序
1. logline（01-规划/logline.md）：主角 + 目标 + 障碍 + 代价/风险，一句话。写不出 logline 就不进入下一层。
2. treatment（01-规划/treatment.md）：2-5 页散文式叙述全片情节，含结局方向；允许叙述具体情节，但不写死台词。
3. structure（01-规划/structure.md）：结构设计。
4. outline（01-规划/outline.md）：剧情大纲——交给 vn-script-outline skill 执行，那里有抽象层级红线。

## 动笔前判定与拍板
- 动笔写结构之前，先判定文本类型（本阶段产出为规划文档）与文风基调（对照 00-设定/style.md），据此按本 skill 的模板正式创作。
- 现有素材不足以支撑结构设计（路线、章节、选项没有思路）时，先给出 2-3 个候选方向与用户讨论，用户拍板后再写入 structure.md；拍板前的推测标注「推测/待拍板」，不混入正式文档。

## structure.md 模板
```markdown
# 结构设计

## 路线划分
共通线 / 个人线（每角色）/ 真结局线的划分、进入条件与相互锁关系。

## 章节结构与节奏
每章：章节功能（序章/日常篇/事件篇/高潮篇/结局篇）、节奏定位、情感单位（本章完成的一次情绪起落）。

## 选项节点
选项编号、大致位置（章/段）、每个选项的后果差异与指向的分支/FLAG。

## 冲突升级
外部冲突与内心冲突的升级阶梯：压力如何逐级加大。

## 情感曲线
全篇情感节奏与转折点：读者/玩家的情绪在何处上扬或下坠。

## 结局方向
可能的结局、各结局的进入条件雏形与主题落点。
```

## 共通线节奏参考
- 三幕逻辑可作为共通线的节奏诊断工具：建置（主角常态、欲望、激励事件、不可逆转折点）→ 对抗（障碍升级、中点改变赌注、低谷）→ 高潮与解决（用第一幕建立的东西完成最后对抗）。
- VN 篇章常按"起承转合"组织：序章建置 → 日常篇埋线与关系升温 → 事件篇冲突爆发 → 高潮篇抉择 → 结局篇收束与主题落点。
- 每章完成一个情感单位（一次完整的情绪起落），章末留钩子（见 writing-craft）。

## 选项设计纪律
- 选项必须有后果差异：影响关系、情报、FLAG 或路线；两个选项后果相同的"假选项"删掉或合并。
- 选项节点节奏大致每 1-3 千字一个有意义的选择；关键抉择放在情感高点，不放平淡段落。
- 每个选项的位置、后果与指向在 structure.md 登记，写入正文时保持一致。

## 检查清单
- [ ] 主角欲望与障碍在序章内明确
- [ ] 关键转折点改变故事方向（不只是时间推进）
- [ ] 中点/高潮改变赌注，且用到了前面建立的设定与关系（不靠天降）
- [ ] 每个章节都有功能，可回答"删掉它损失什么"
- [ ] 每个选项都有后果差异，每个结局方向都能追溯到已建立的人物动机与世界观规则
