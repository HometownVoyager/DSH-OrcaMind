# 评论体规范（spec-commentary，定稿版 2026-09-10）

> 用途：开工规范检查选默认集「评论体」时，本 skill 是 `规范-议题.md` 的内容母本（四节骨架、写法通则与执行要求的纳入方式见 spec-common；落盘时记录来源为「本预设默认集·评论体（2026-09-10 定稿）」）；A 轨成文阶段随时对照执行。

## ① 来源记录
- 新闻时评/评论文章写作通则（新闻评论学通行体例与专业媒体评论写作规范整理）；
- 定稿时间：2026-09-10（据检索摘要提炼，用户批注修订后复请确认）。

## ② 结构与目录约定
- 标题（观点式标题，直接亮明判断或以问句设悬）→ **由头**（引述新闻事实，交代 5W 要素，简短）→ **论点**（全文只有一个中心论点，由头之后尽快亮出）→ **论证**（2–4 层：事实论据 + 说理；预置对相反观点的回应）→ **收束**（回到现实针对性，不喊口号）。
- 一事一议：一篇评论只处理一个议题；系列评论可拆分多篇分别立项。
- **论证须含机制**（定稿增补 2026-09-10）：不止于表态——写清议题如何发生、通过什么链条影响谁；把议题放进关联背景（历史脉络、相关政策、利益相关方网络）中考量，呈现事物之间的联系，避免孤立就事论事。
- 项目目录按「01-议题文章/」：选题立意.md → 考据/ → 论证框架.md → 成稿/ → 修订记录.md。

## ③ 产出格式规范
- 篇幅以千字文为主流（800–1500 字），由头不超过全文 1/5；段落以完整复合句为主。
- 事实与观点严格分轨：新闻事实部分须可溯源（注明时间、地点、信源），评论部分明确标注为作者判断；信源在文末或文中注明（媒体名 + 日期）。
- 论证框架先落盘 `论证框架.md`（论点/论据/反驳预案）再成文，成稿与框架一致。
- **考据升级（定稿增补 2026-09-10，配合 search-query-craft）**：围绕议题广泛 web_search——事实经过、各方立场、已有评论与反驳、数据与政策原文多角度检索，检索词按「搜索词联想构建」展开；关键事实双源以上交叉验证，检索与核查记录落 `01-议题文章/考据/`。

## ④ 红线与禁忌
- 禁止人身攻击、贴标签、诛心之论；批评对事不对人。
- 禁止把推测当事实：未经核实的传闻不得作为论据；信源存疑时明确标注并在 `考据/` 留核查记录。
- 禁止情绪化煽动与对立化修辞；避免「所有」「从来」一类以偏概全表述。
- 禁止观点骑墙：论点必须明确可反驳；「一方面…另一方面」的平衡腔不得替代判断（分析文另走研究报告体）。
- 禁止以表态代替论证（定稿增补 2026-09-10）：每一层论证须能回答「依据是什么、机制是什么、对谁有何影响」；空泛的立场句不算论据。

## 执行要求（写入 规范-议题.md 时随结构节一并纳入）
- 成文前 `论证框架.md` 必须经用户确认；成稿与框架逐层对应，新增事实必须同步补考据记录。
- 修改定稿按 article-revision 执行，重点核查：论点唯一性、事实可溯源、机制完整性、是否残留骑墙与空话。
