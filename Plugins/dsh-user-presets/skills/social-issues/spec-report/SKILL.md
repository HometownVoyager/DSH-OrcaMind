# 研究报告体规范（spec-report，定稿版 2026-09-10）

> 用途：开工规范检查选默认集「研究报告体」时，本 skill 是 `规范-议题.md` 的内容母本（四节骨架、写法通则与执行要求的纳入方式见 spec-common；落盘时记录来源为「本预设默认集·研究报告体（2026-09-10 定稿）」）；B 轨方法论报告成稿随时对照执行。

## ① 来源记录
- 社会调查报告/政策研究报告通用体例（高校调查报告撰写规范与智库报告通行结构综合）；
- 定稿时间：2026-09-10（据检索摘要提炼，用户批注修订后复请确认）。

## ② 结构与目录约定
- 标题 → 摘要（核心发现与建议各一条以上）→ 一、背景与研究问题 → 二、研究方法与数据来源 → 三、现状与问题分析（分层：现象 → 数据 → 成因）→ 四、对策建议（与分析逐条对应）→ 五、结论与展望 → 参考文献与附录（不编号；问卷、访谈提纲、数据表）。
- 编号用「一、（一）1.」体系；图表随文编号并注明数据来源。
- 项目目录按「02-方法论/」双轨分立（问题定义.md → 根因分析.md → 方案对比.md → 落地路径.md → 复盘.md，另含 考据/ 与 成稿/）。
- 可行性与代价评估无独立文件，其结论回填 方案对比.md；B 轨文档链为 问题定义.md → 根因分析.md → 方案对比.md → 落地路径.md → 复盘.md 五个文件 + 考据/ 与 成稿/。
- **落盘规则：按所在轨目录落盘**——B 轨项目（或双轨项目的 B 轨）成稿落 `02-方法论/成稿/`；**A 轨**成文阶段若加载本规范（分析文改走研究报告体），产出仍落 A 轨的 `01-议题文章/`，不得因加载本规范而写进 `02-方法论/`。简言之：**规范决定写法，轨道决定落点**。
- **方法论为报告重心**（定稿增补 2026-09-10）：问题定义、根因分析、方案对比须给出可复用的分析路径（框架、步骤、判据），而非只给结论；分析须呈现事物间联系——问题间关联、政策间相互作用、二阶与长期效应。

## ③ 产出格式规范
- 方法与数据来源单独成节：调查方法、样本量与构成、时间范围、局限性必须交代；二手数据注明原始出处与统计口径。
- 每条建议具备三要素：针对哪个问题（与分析节编号呼应）、由谁执行、如何验收；建议与问题一一对应，不出现无分析支撑的建议。
- 引用与信源按文末参考文献或脚注著录，区分一手与二手信源。
- **检索与考据升级（定稿增补 2026-09-10，配合 search-query-craft）**：围绕研究问题广泛 web_search（学术、政策、统计、媒体多源），检索词按「搜索词联想构建」展开；二手数据回溯原始出处并交叉验证，检索与核查记录落 `02-方法论/考据/`。
- **多方面考虑（定稿增补 2026-09-10）**：对策前完成利益相关方检视（谁受益、谁受损、谁执行、谁监管）与时间尺度检视（短期/长期）；每条建议注明所依据的分析条目。

## ④ 红线与禁忌
- 数据必须有出处：禁止无来源数据、「据了解」「有人说」入正文；样本不足以支撑的结论须写明置信边界。
- 禁止问题分析与对策建议脱节（问题 5 条建议 3 条且无对应关系）；禁止建议空泛到不可执行（「加强」「完善」必须落到具体动作与责任主体）。
- 禁止把价值判断伪装成实证结论：规范性与实证性内容分节或明确标注。
- 涉及敏感人群数据须匿名化处理；引用政策文件以现行有效版本为准并注明文号。
- 禁止建议停留在单点（定稿增补 2026-09-10）：对策须检验与其他政策/系统的相互作用及二阶效应；检验不到处如实标注，不得以「影响有限」一笔带过。
- 禁止空话入正文（定稿增补 2026-09-10）：「高度重视」「进一步完善」「形成合力」类表述不得单独作为问题诊断或对策内容。

## 执行要求（写入 规范-议题.md 时随结构节一并纳入）
- 报告各节优先引用既有双轨文档（问题定义/根因分析/方案对比/落地路径）的定稿内容，报告是对它们的整合成文，不另起炉灶推翻已确认分析。
- 修改定稿按 article-revision 执行，重点核查：方法节完整性、建议与分析逐条对应、二阶效应检视是否留痕、是否残留空话。
