# 资产制造·生图产出（asset-make-generate）

## 何时使用
VN-资产制造（vn-asset-make）阶段 Do 步：在 `asset-make-spec-read` 已只读锁定、且用户已确认「本轮就做这一个」之后，按已确认规格逐条实际调用生图工具，产出本轮唯一 1 个资产文件。

## 唯一落点 / 写死路径
- **唯一允许产出落点写死为 `<作品名>/03-Asset/generated/`**；`<作品名>/03-Asset/generated/` 是唯一二进制资产落点。
- 七类分类子目录写死为：`<作品名>/03-Asset/generated/bg/`、`sprite/`、`cg/`、`bgm/`、`sfx/`、`ui/`、`script/`。资产文件按规格单的分类写入对应分类子目录。
- 不在其它任何位置写文件：不在 `<作品名>/03-Asset/generated/` 及其七类子目录之外的任何路径落盘一个字节。
- 不创建任何清单、规范、记录、草稿、索引类文档与计划外文件/目录；本 skill 只产出那 1 个资产文件（含其分类子目录）。
- `asset-index.md` / `asset-gap.md` 的实际状态补写由 `asset-make-status-sync` 承担，本 skill 不写入；README.md 的更新由 `asset-make-verify` 承担，本 skill 不写入。

## 调用生图工具前的强制询问（未确认不调用）
- **每轮调用前应用 `ask_user_question` 询问用户选 ComfyUI 本地 / Nano Banana 2 在线 / 其它，并确认参数**；未经用户当场确认工具与参数，**不调用任何生图工具**。
- 提问须具体、简洁、给可选方案（ComfyUI 本地 / Nano Banana 2 在线 / 其它），并同时确认分辨率、尺寸、文件名、格式、种子等参数；用户未确认的不执行。
- 生图工具**暂不绑定**（决策「再说吧」），后续可加 ComfyUI 或 Nano Banana 2，届时更新本预设工具行；在此之前不假定、不预接、不偷跑任何一套工具。
- 规格单、生成提示词、分类、文件名、工具选择、参数以用户已确认的内容与用户当场拍板为准。

## 单轮单条目
- 每轮只处理 1 个子条目（1 个资产文件）：只按那 1 条已确认资产条目产出 1 个文件，具体到分类子目录、文件名、格式、生成提示词四项。
- 不把「一类资产」「一份清单」「多张图」「补齐缺口」当作一个子条目；不一次性交付多份文件；不在本轮内规划或预写后续子条目；子条目由用户从候选清单中选定，不自主规划本阶段子任务。
- 按规格单原样执行，不自行修改规格、不自行增补提示词、不「顺手把缺口也补了」；发现规格单内部矛盾应停下询问，不自行调和。

## 执行要点
1. **每轮只处理 1 个子条目**：见上节，一轮只产出 1 个资产文件。
2. **不跨阶段**：不读写下游阶段目录，不创建下游文件，不在对话中替下游做设计；不做上游阶段的事（不写资产清单、规格单、生成提示词），不做下游阶段的事（不写逐场演出剧本、不写游戏实现规格、不搭建工程骨架）。

其余同等强制的硬约束：
- 不在 `<作品名>/03-Asset/generated/`（含七类子目录）之外的任何位置写文件，不创建任何清单/规范/记录/索引类文档。
- 不自行修改规格、不自行增补提示词、不顺手补缺口；产出文件默认与规格单逐字对应。
- 不伪造资产路径、资产 ID、差分名；不用占位内容冒充成品；不生成规格单之外的任何文件。
- 唯一产出落点是 `<作品名>/03-Asset/generated/`（`asset-make-status-sync` 对 `asset-index.md` / `asset-gap.md` 实际状态字段的协作补写是唯一例外，且只补实际状态字段）。
- 用户未确认工具与参数时调用任何生图工具即违反红线，应立即停下并询问用户。

## 越界收敛原则
默认优先把改动限制在 `03-Asset/` 本列内；确有必要越出本列时只允许「读上游已确认内容」与「按 vn-gate 在 README.md 追加一行进度」，不借「有必要」扩张写权。本 skill 只在 `<作品名>/03-Asset/generated/` 七类子目录内落盘那 1 个资产文件，任何越界写入默认收敛、停下询问。违反任意一条应立即停下并询问用户。

## README.md 双区结构
`<作品名>/README.md` 是唯一进度载体，双区结构（见 `vn-gate` §4）：A 区「当前状态」块 5 字段（当前预设 / 当前阶段 / 本轮子条目 / 状态(进行中|待确认|已确认) / 下一候选）仅在用户确认后就地更新；B 区「进度记录」区只追加一行、永不改写或删除既有行。本 skill **不写 README.md**；A 区字段就地更新与 B 区追加一行由 `asset-make-verify` 承担，AI 不自行把状态置为「已确认」。
