# 头脑风暴（vn-brainstorm）

## 何时使用
- 项目处于 Brainstorm 阶段（阶段1），或用户要求回到创意原点重新讨论定位时。

## 本阶段边界
本阶段只回答「这是一部什么样的作品」，不写角色细节、世界观规则与具体剧情；发现这些想法时记入开放问题，留给后续阶段。

## brainstorm.md 模板（00-设定/brainstorm.md）
```markdown
# Brainstorm：<暂定名>

## 核心创意
一句话说明故事前提：谁在什么样的处境里追求什么。

## 主题与立意
作品想探讨的核心主题，以及主题在体验上的落点。

## 情绪基调
主基调（如悬疑、治愈、浪漫、压抑）与情绪变化范围。

## 目标体验
玩家体验目标（沉浸感/心流/情感冲击），参考平台与预计游玩时长。

## 类型融合
主类型与融合类型，以及每种类型各自提供的体验。

## 核心卖点
与同类作品相比的差异化，以及目标受众的期待点。

## 开放问题
未决的创意缺口与候选方向。
```

## 执行步骤
1. 先请用户说出已有的想法，哪怕只是零散的关键词、画面或情绪。
2. 按模板把素材组织成候选方向（通常给出 2-3 个有差异的方向供选择）。
3. 每个方向点明代价与收益（制作复杂度、受众、时长），请用户裁决后再写入正式设定。

## 注意事项
- 用户未明示的创意缺口列进开放问题，不自行补全后直接写进正文。
- 类型惯例与市场参考可用联网搜索，必须注明来源，并区分事实信息与创作建议。
- 本阶段产出的定稿是后续所有阶段的基准参照，后续内容冲突时先回溯到这里。
