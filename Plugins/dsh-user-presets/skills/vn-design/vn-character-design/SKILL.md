# 人物设定（vn-character-design）

## 何时使用
- 项目处于人物设定阶段（阶段2），或需要新增角色、补充已确认角色的细节时。

## 角色档案模板（00-设定/characters/<角色名>.md）
```markdown
# <角色名>

## 档案
- 定位：主角 / 可攻略角色 / 核心配角 / 反派
- 目标：长期目标与当前阶段目标
- 动机：驱动行为的深层原因（与世界观、经历挂钩）
- 性格：核心特质、表面与内在的反差、雷点与软肋
- 外貌：标志性特征、服装风格、可供立绘参考的形象要点
- 成长弧线：从起点到终点的变化轨迹

## 人际关系
与其他角色的关系定位、冲突点与关系变化方向。

## 与主线的关系
该角色如何承载主题、推动或阻碍主线。

## 补充设定（按需）
口头禅、习惯动作、能力、秘密等。
```

## relationships.md
记录角色间的关系网与变化方向，作为剧情大纲与路线设计的输入。

## 执行步骤
1. 与用户确认主要角色数量与各自定位（哪些可攻略、谁承载主线）。
2. **先锚点后档案**：逐个角色先把出生/基准年龄、关键节点年龄（生日/成人礼/学段）与生理核心事实写入 `00-设定/anchors.md` 第一节「年龄与生理时间轴矩阵」，把系统 Speaker ID 与各视角称谓口径写入第三节「称谓三层解耦网格」，经用户确认后再建角色档案。
3. 逐个建立档案，先写目标与动机，再写性格与外貌；档案中年龄与称谓字段引用锚点，不另写一套口径。
4. 全角色复核：彼此的动机能否相互对抗或支撑，成长弧线是否与主线咬合。

## 注意事项
- 每个角色的目标与动机必须形成戏剧张力，动机空泛的角色先提出补充问题，不硬写。
- 人物设定若与后续世界观或大纲冲突，先请用户裁决再修改档案；改年龄/称谓类常量事实先改 anchors.md 并经用户裁决。
- 外貌部分写清供立绘参考的要点；不可变体貌特征（发型/发色/瞳色）同步记入 anchors.md 第四节「核心资产与体态状态机」的体貌锚点字段，防止下游剧本与资产阶段漂移；表情与服装差分需求记录到该文件，资产阶段汇总。
