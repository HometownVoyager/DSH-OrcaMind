# 世界观设定（vn-worldbuilding）

## 何时使用
- 项目处于世界观设定阶段（阶段3），或需要补充、修订已确认的世界观细节时。

## world.md 模板（00-设定/world.md）
```markdown
# 世界观：<世界名>

## 核心规则
世界运转的底层规则；超自然或特殊规则要写明机制、代价与边界。

## 历史
关键历史事件与因果链，事件之间如何连锁。

## 社会结构
制度、阶层、文化习俗与日常生活的质感。

## 与主题的关联
世界观规则如何服务主题与主线因果。

## 开放问题
未决或需要用户裁决的设定缺口。
```

## factions.md —— 势力与组织（00-设定/factions.md）
各势力的名称、定位、目标、资源、组织结构与相互冲突格局；与主要角色的隶属或对立关系。与小说、剧本预设同粒度，便于下游直接引用。

## geography.md —— 地理与地点（00-设定/geography.md）
主要地点列表：名称、位置关系、气候与风貌、功能；同一地点的空间布局保持一致（门在哪、桌在哪），供下游剧本与资产参考。

## 辅助文件
- timeline.md：历史年表，按时间顺序记录已确认事件。
- glossary.md：专有名词表（地名、组织、术语、特殊规则名），新名词先登记再使用。

## 执行步骤
1. 从核心规则与历史出发搭建骨架，再补地理（geography.md）、社会结构与势力（factions.md）。
2. **先空间拓扑后地理**：为常驻空间（主角居所、工作场所等高频场景）先把建筑属性（楼层/电梯或步梯）、户型、动线连接与声光穿透法则写入 `00-设定/anchors.md` 第二节「空间拓扑与动线模型」，再写 geography.md 的风貌类信息——上下楼方式、房门朝向、视线遮挡必须唯一确定，杜绝下游剧本穿帮。
3. 逐条自检规则：同一规则在所有场合表现一致，代价与边界清晰。
4. 与已确认的人物动机、主线走向核对，发现冲突先提出裁决。

## 注意事项
- 世界观规则必须能服务剧情，尤其是超自然或特殊规则要与主线因果挂钩，不堆砌无用的设定。
- 新增规则影响已确认内容时，先提出确认请求，不得直接改写旧设定。
- 需要事实考据（历史、民俗、科技等）时使用联网搜索，注明来源并区分事实信息与创作建议。
