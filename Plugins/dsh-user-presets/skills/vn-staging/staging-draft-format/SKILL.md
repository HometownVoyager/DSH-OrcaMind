# 演出中间稿格式（staging-draft-format）

## 何时使用
- 撰写任何一场演出中间稿之前（先确认格式，再动笔）。
- 定稿某一稿次之前。
- 审阅既有场次稿、判断它是否合格时。
- 起草或修订 `规范-演出.md` 时（本 skill 的要点是默认规范的来源）。

## 场次编号体系
- 场次编号为 `SC-` 加三位十进制递增：`SC-001`、`SC-012`、`SC-100`。
- 编号一经分配不复用；拆分与合并产生的新编号顺延，旧编号在 `scene-map.md` 中标注去向。
- 每场必须登记与上游剧本的对应关系（章-段），格式如 `ch003-2a`；一场覆盖多段时全部列出，跨章时全部列出。
- 稿次用目录区分：`draft-v1/`、`draft-v2/`；新稿次不覆盖旧稿次，以便回溯。

## 中间稿模板

```markdown
# SC-012 ｜ 天台·黄昏 ｜ 对应上游 ch003-2a

- 场次功能：<推进情节／揭示人物／埋设信息，一句话>
- 上游视点：<【视点：角色】／【视点：全知】，与上游剧本场景头保持一致；上游未声明时写「继承默认主视点」>
- 出场：悠里（左→中）、<角色>（右）
- 背景：`BG_ROOFTOP_DUSK`（available）
- BGM：`BGM_TENSE_LOW`（substitute ← 原需求 `BGM_ANXIETY_02`）
- 环境音：风声底噪（`SFX_WIND_LOW`，available）
- 音效：`SFX_DOOR_OPEN`（available）
- 转场入：淡入 1.5s ｜ 转场出：淡出 1.0s

**演出**
1. …
2. …

**缺口与标注**
- `CG_YURI_ROOFTOP`：missing ｜ 处理：本场降级为立绘 + 背景 ｜ 状态：已裁决 <日期>
```

不适用的小节写「无」并给出理由，不要留空。确实用了默认值（如本场无音效）时写明「无音效：本场为静场设计」。

## 资产引用语法
- 资产一律写成反引号包裹的 ID：`` `BG_ROOFTOP_DUSK` ``。
- ID 后紧跟括号状态：`` `BG_ROOFTOP_DUSK`（available） ``。状态取自统一词表：`available`、`generated`、`substitute`、`placeholder`、`missing`、`hard_missing`、`pending`；缺口类别 `listed_but_missing` 只在缺口表与标注区使用。
- 替代类要写出来源：`` `BGM_TENSE_LOW`（substitute ← 原需求 `BGM_ANXIETY_02`） ``。
- 非 `available` 的引用必须在 **缺口与标注** 区有对应条目，两边一一对应。
- **不写路径、不写扩展名、不写引擎资源加载语法**。

## 演出步骤书写规则
- 按有序列表逐步写，一步一个可执行画面状态，不要把三件事塞进一行。
- 每步至少包含：画面状态（谁在哪、什么背景）→ 资产引用 → 动作或台词 → 时机。
- 台词引用要带上游定位（如 `ch003-2a-04`），并保留原文措辞；你不改写台词，只整理与标注演出。
- 时机用秒数或相对描述（「约 2s」「与下一句台词同步」「略长于一拍」）表达意图，不写缓冲曲线、缓动函数与帧数。
- 一场戏的步骤数超过约 25 步时，检查是否应该拆场。
- 步骤中不要出现「略」「等等」「若干」这类含糊量词，要么给量级，要么标注为待确认。

## 常见错误（自检时逐条对照）
| 错误 | 危害 | 正确做法 |
|------|------|----------|
| 写了引擎命令或路径 | 越过输出边界，下游无法区分意图与实现 | 只写意图与 ID |
| 引用磁盘上不存在的 ID | 伪造资产，下游必然返工 | 走缺口流程或标 `pending` |
| 引用了索引里没有的立绘差分 | 同上，且立绘差分最易编造 | 只用索引中实际列出的差分 |
| 引用了资产但不写状态 | 缺口不可见，验收时无从核查 | ID 后紧跟状态 |
| 标注区与引用不一致 | 一处说缺、一处当有，事实源冲突 | 两边逐条对齐 |
| 改写了上游台词 | 越权修改已确认内容 | 保留原文，意见写进标注区并请裁决 |
| 缺口只写在对话里没落盘 | 长流程丢失上下文 | 一律写入 `资产缺口.md` 与标注区 |
| 全场只有「立绘 + 台词」 | 演出密度单一，缺少设计 | 按 `staging-direction` 增加变化 |

## 完整示例（一场戏）

```markdown
# SC-012 ｜ 天台·黄昏 ｜ 对应上游 ch003-2a

- 场次功能：揭示悠里已知晓转学一事（推进情节 + 揭示人物）
- 上游视点：【视点：悠里】（与上游场景头一致；本章为限知视点，悠里之外的角色内心不可写）
- 出场：悠里（左 → 中）
- 背景：`BG_ROOFTOP_DUSK`（available）
- BGM：`BGM_TENSE_LOW`（substitute ← 原需求 `BGM_ANXIETY_02`）
- 环境音：风声底噪（无对应资产，标 `missing`，暂以静默处理）
- 音效：`SFX_DOOR_OPEN`（available）
- 转场入：淡入 1.5s ｜ 转场出：淡出 1.0s

**演出**
1. 淡入 1.5s。远景：空旷天台，晚霞低垂。`BG_ROOFTOP_DUSK`（available）
2. 悠里自画面左侧入画 `SP_YURI_UNIFORM`（available），表情 normal，站位左。
3. 台词（ch003-2a-04）「……你今天来得很早。」——语气刻意放平，与平日不同。表情在台词中段切至 worried。
4. 立绘位移：左 → 中，与第 3 步同步，缓步。
5. 原定 CG `CG_YURI_ROOFTOP`（missing）本场降级为立绘 + 背景，张力损失记入演出精述。
6. 静默约 2s：让上一句落地，镜头与立绘保持不变。
7. 台词（ch003-2a-05）「我看到了。教务处的通知。」——说罢移开视线，表情维持 worried。
8. 淡出 1.0s，转场至 SC-013。

**缺口与标注**
- `CG_YURI_ROOFTOP`：missing ｜ 处理：本场降级为立绘 + 背景 ｜ 状态：已裁决 <日期>
- `BGM_ANXIETY_02`：listed_but_missing ｜ 处理：以 `BGM_TENSE_LOW` 替代 ｜ 状态：已裁决 <日期>
- 环境音风声：missing ｜ 处理：本场以静默处理，建议补录 ｜ 状态：待裁决
```

## 定稿检查
落盘前确认：格式符合本 skill 与 `规范-演出.md`（冲突时以规范文档为准）；上游视点声明已保留且与上游剧本场景头一致；所有引用带状态；所有非 `available` 引用在标注区有条目；无路径、无引擎语法；台词保留原文；场次号与 `scene-map.md` 一致。然后按 `staging-continuity` 执行一致性核查，按 `staging-acceptance` 执行交付验收。
